Slider

1소개

Slider 컴포넌트는 사용자가 상하 또는 좌우로 핸들을 슬라이딩하여 연속적인 값을 직관적으로 선택할 수 있는 인터페이스를 제공합니다. 사용자는 시각적이고 직관적인 방식으로 값을 조절할 수 있어 사용자가 연속적인 데이터 범위에서 특정 값을 선택해야 할 때 매우 유용합니다. Slider 컴포넌트는 최소값과 최대값 사이에서 핸들을 이동하여 원하는 값을 설정할 수 있으며, 수직 또는 수평 방향으로 배치가 가능합니다. 이 컴포넌트는 다양한 사용자 입력 시나리오에서 유용하게 활용되며, 시각적으로도 직관적인 입력 방식을 제공합니다. 반응형 레이아웃과 함께 사용할 경우, 다양한 화면 크기에서도 유연하게 동작합니다.

2주요 용도 및 특징

Slider 컴포넌트는 다음과 같은 상황에서 효과적으로 사용할 수 있습니다.

수치 조절

볼륨 조절, 밝기 설정, 줌 레벨 등 연속적인 값을 조절할 때 주료 사용합니다.

범위 내 선택

0~100 사이의 퍼센트 입력, 날짜 범위 내의 시점 설정 등 가격 범위, 연령대, 시간 범위 등 특정 범위 내에서 값을 선택할 때 유용합니다.

시각적인 조작 경험 제공

사용자에게 현재 값이나 진행 상태를 시각적으로 표현하여 제공할 수 있습니다.

인터랙티브 폼

사용자 경험을 향상시키는 인터랙티브한 폼 요소로 활용할 수 있습니다.

확대/축소

지도나 이미지 뷰어에서 확대/축소 수준을 조절하는 데 Slider를 활용하여 사용자가 원하는 배율을 부드럽게 선택할 수 있습니다.

3주요 기능

  • 기본 기능

    • 방향 설정 – vertical

    • 최소값/최대값 설정 – setMinValue() , setMaxValue()

  • 증감 단위 설정 – increment

  • 반응형 디자인 지원 (샘플)
