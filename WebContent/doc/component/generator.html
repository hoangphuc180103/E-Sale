Generator

1소개

Generator 컴포넌트는 여러 개의 컴포넌트로 이루어진 UI 그룹을 반복적으로 생성할 수 있도록 설계된 WebSquare AI 전용 컨테이너입니다. 예를 들어 입력 박스, 라벨, 버튼 등으로 구성된 입력 폼 그룹을 반복적으로 생성해야 할 때, Generator를 이용하면 효율적이고 일관된 방식으로 화면을 구성할 수 있습니다. 이 컴포넌트를 통해 개발자는 복잡한 UI 패턴을 효율적으로 구현하고, 사용자의 요구에 따라 동적으로 인터페이스를 변경할 수 있습니다.

2주요 용도 및 특징

Generator 컴포넌트는 다음과 같은 상황에서 특히 유용합니다.

폼 요소 동적 추가

사용자가 필요에 따라 입력 필드를 추가하거나 제거할 수 있는 동적 폼을 구현할 수 있습니다. (예: 가족 정보 입력, 파일 첨부 목록 등)

목록 항목 관리

쇼핑 카트, 연락처 목록 등에서 항목을 동적으로 추가/삭제하는 기능을 제공할 수 있습니다.

설문조사 인터페이스

질문 수가 가변적인 설문조사나 피드백 폼을 구현할 수 있습니다.

Generator 컴포넌트는 UI 개발 과정에서 다음과 같은 주요 특징과 이점을 제공합니다.

동적 UI 구성

런타임에 필요한 만큼 UI 컴포넌트를 동적으로 생성하거나 제거하여 유연한 사용자 인터페이스를 구축할 수 있습니다. 이는 미리 모든 요소를 로드할 필요 없이, 사용자 상호작용에 따라 필요한 부분만 구성하여 애플리케이션의 효율성을 높입니다.

재사용성 및 모듈화

반복되는 UI 요소를 Generator 컴포넌트 내부에 한 번만 정의하고, 이를 필요에 따라 여러 번 복제하여 사용할 수 있습니다. 이를 통해 코드의 재사용성을 높이고 유지보수를 용이하게 합니다.

개발 생산성 향상

반복적이고 정형화된 UI 요소를 자동화된 방식으로 생성함으로써, 개발자가 수작업으로 코드를 작성하는 시간을 줄여 개발 생산성을 향상시킵니다.

3주요 기능

  • 컴포넌트 그룹 반복 생성 (샘플, YouTube)

  • 아이템 추가, 삭제, 반복부 컴포넌트 제어 (WRE)

  • Generator를 이용한 Accordion 생성 예시 (WRE)
