Calendar

1소개

Calendar 컴포넌트는 웹스퀘어 AI에서 제공하는 날짜 선택 전용 UI 구성 요소입니다. 사용자는 마우스 클릭만으로 원하는 날짜를 간편하게 선택할 수 있으며, 복잡한 로직 없이 화면에 달력을 손쉽게 구성할 수 있습니다. 해당 컴포넌트는 InputCalendar와 유사하지만, 사용자가 직접 텍스트 입력을 통해 날짜를 입력할 수는 없습니다. 오직 달력 UI를 통해서만 날짜를 선택하도록 제한되어 있습니다. 따라서 직관적이고 시각적으로 날짜를 선택해야 하는 상황에 적합합니다.

2주요 용도 및 특징

본 Calendar 컴포넌트는 주로 다음과 같은 용도로 활용됩니다.

날짜 선택 수단

웹 페이지 상에 달력을 출력하여 사용자가 원하는 날짜를 쉽고 빠르게 선택할 수 있도록 지원합니다.

날짜 형식 및 범위 제어

지정된 날짜 형식(calendarValueType)을 이용하여 오늘 날짜부터 특정 기간 내의 날짜만 선택하도록 설정할 수 있습니다. 또한, 최소/최대 연도(minYear, maxYear)를 설정하여 허용되는 연도 범위를 제한할 수 있습니다.

휴일 및 특수 날짜 관리

함수(setHoliday, setHolidayRef, removeHoliday)를 통해 특정 날짜를 휴일로 지정하거나, 이미 지정된 휴일 값을 취소할 수 있습니다. 이는 예약, 일정 관리 등 다양한 웹 애플리케이션에서 유용하게 사용됩니다.

외관 및 사용자 인터페이스의 세밀한 조절

달력의 시작 요일, 디자인 스킨, Today 버튼의 위치 등 다양한 인터페이스 옵션을 통해 웹사이트의 전체 디자인과 일관성을 유지할 수 있습니다.

3주요 기능

  • 기본 사용법

    • 시작 요일 지정 – weekStartson

    • Today 버튼 위치 설정 – topLayout

    • 날짜 표시 형식 지정 – calendarValueType

  • 날짜 선택 제한

    • 오늘 날짜 기준 선택 제한 (YouTube)

    • 특정 날짜 기준 선택 제한 – disableAfterDate , disableBeforeDate , enableAllDate

  • 날짜 표시 커스터마이징

    • 선택한 주를 다른 색으로 표시 (샘플, YouTube)

    • 달력 주(Week) 수 설정 (WRE, 샘플, YouTube)

    • 달력의 요일을 이미지 또는 텍스트로 표시 (WRE, 샘플, YouTube)

  • 휴일 관리

    • 휴일 직접 지정 (WRE, 샘플, YouTube)

    • DataList의 날짜를 휴일로 지정 (WRE, 샘플, YouTube)

    • 휴일 지정 취소 (WRE, 샘플, YouTube)
