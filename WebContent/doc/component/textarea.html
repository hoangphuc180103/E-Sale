TextArea

1소개

TextArea 컴포넌트는 사용자가 여러 줄의 텍스트를 입력할 수 있도록 도와주는 UI 구성 요소입니다. HTML의 <textarea> 요소와 유사한 기능을 제공하며, InputBox와 달리 여러 줄의 텍스트 입력이 가능하여 보다 긴 내용의 텍스트를 처리할 수 있습니다. 개발자는 TextArea 컴포넌트를 통해 단순한 메모 형식부터 사용자 의견, 긴 텍스트 필드 입력 등 다양한 입력 요구에 대응할 수 있습니다. 일반적으로 사용자가 긴 텍스트를 입력해야 하는 경우에 활용됩니다.

TextArea는 단순 텍스트 입력보다 더 많은 내용을 다루어야 할 때 InputBox 컴포넌트 대신 사용하는 것이 적합합니다. 특히 사용자가 자유롭게 텍스트를 입력하고 편집할 수 있는 넓은 공간이 필요한 경우에 이상적입니다.

2주요 용도 및 특징

TextArea 컴포넌트는 다음과 같은 상황에서 효과적으로 활용할 수 있습니다:

긴 텍스트 입력

사용자 의견, 댓글, 리뷰 등 여러 줄의 텍스트 입력이 필요한 경우 사용할 수 있습니다.

텍스트 편집

기존 텍스트 내용을 편집하거나 수정해야 하는 경우 유용합니다.

멀티라인 표시

여러 줄로 구성된 데이터를 표시할 수 있습니다.

폼 제출

대량의 텍스트 데이터가 포함된 폼을 제출해야 하는 경우 유용합니다.

메모 또는 노트 기능

사용자에게 자유로운 텍스트 입력 공간을 제공하여 메모 기능을 구현할 수 있습니다.

3주요 기능

  • Placeholder

    • Placeholder 설정 (WRE)

    • 읽기 전용 혹은 비활성화 상태에서 Placeholder 표시 (WRE, 샘플, YouTube)

  • CSS로 리사이징 (WRE)

  • 상태 관리 기능

    • 읽기 전용 모드 – readOnly

    • 비활성화 상태 – disabled

  • 필수 입력 표시 – mandatory

  • 최대 길이 제한 – maxByteLength , maxLength
