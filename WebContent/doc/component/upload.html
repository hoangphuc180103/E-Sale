Upload

1소개

Upload 컴포넌트는 사용자가 로컬 시스템에서 서버로 단일 파일을 업로드할 수 있는 기능을 제공합니다. 단일 파일 업로드에 최적화된 구조를 가지고 있으며, MultiUpload 컴포넌트와는 다르게 한 번에 하나의 파일만 업로드할 수 있도록 설계되었습니다. 직관적인 인터페이스를 통해 사용자는 쉽게 파일을 선택하고 업로드할 수 있으며, 개발자는 다양한 속성과 이벤트를 활용하여 업로드 프로세스를 세밀하게 제어할 수 있습니다.

Upload 컴포넌트는 사용자 인터페이스가 간결하고 직관적이어야 하는 상황에서 특히 유용합니다. 여러 파일을 동시에 업로드해야 하는 복잡한 시나리오에서는 MultiUpload 컴포넌트를 대신 사용하는 것이 좋습니다.

2주요 용도 및 특징

Upload 컴포넌트는 다음과 같은 용도로 활용될 수 있습니다:

단일 파일 업로드

MultiUpload 컴포넌트와 달리 한 번에 하나의 파일만 업로드할 수 있는 상황에 적합합니다.

사용자 프로필 이미지 업로드

사용자가 프로필 사진을 변경할 때 사용할 수 있습니다.

게시판 파일 첨부

게시물 작성 시 이미지, 문서 등 다양한 파일을 첨부할 때 사용됩니다.

문서 제출 시스템

이력서, 신청서 등의 단일 문서를 제출하는 경우에 활용할 수 있습니다.

단순한 파일 공유

복잡한 다중 파일 업로드 기능이 필요하지 않은 간단한 파일 공유 기능에 적합합니다.

포맷 제한 업로드

특정 파일 형식만 업로드를 허용해야 하는 경우 사용됩니다.

3주요 기능

  • 최대 업로드 용량 제한 – subSize

  • 파일 탐색창 열기

    • 입력창을 클릭해서 파일 탐색기 열기 (샘플, YouTube)

    • 함수를 사용하여 파일 탐색기 열기 (샘플, YouTube)
