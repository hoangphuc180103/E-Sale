SearchBox

1소개

SearchBox 컴포넌트는 웹 화면 상에서 검색어 입력을 위한 텍스트 입력 상자를 제공합니다. 사용자로 하여금 직관적으로 키워드를 입력하고, 입력 내용을 바탕으로 원하는 정보를 빠르게 검색할 수 있도록 도와줍니다. 기본적으로 일반 InputBox와 동일한 기능을 수행하면서도, 전체 텍스트를 한 번에 삭제할 수 있는 버튼을 제공합니다.

2주요 용도 및 특징

SearchBox는 다음과 같은 용도로 사용됩니다:

검색 기능 구현

웹 페이지나 애플리케이션 내에서 콘텐츠를 검색하는 기능을 제공합니다.

양식 입력 보조

주소, 상품명 등 미리 정의된 데이터 목록에서 검색어를 입력하여 자동 완성 기능을 제공, 사용자 입력을 돕습니다.

필터링 입력

데이터 목록 또는 테이블의 필터링을 위한 검색어를 입력할 때 유용합니다.

데이터 조회

특정 조건에 맞는 데이터를 조회하기 위한 검색 조건 입력할 때 사용할 있습니다.

3주요 기능

  • 텍스트 입력 및 삭제

  • Placeholder 설정 – placeholder , setPlaceholder() , showPlaceHolderReadOnly

  • 읽기 전용 및 비활성화 모드

  • ref 속성을 통한 바인딩 설정 (샘플, YouTube)

  • 스타일 커스터마이징

  • 검색 아이콘 커스터마이징
