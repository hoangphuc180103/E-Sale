MultiSelect

1소개

MultiSelect는 웹스퀘어 AI 플랫폼에서 제공하는 사용자 다중 선택 기능을 지원하는 UI 컴포넌트입니다. SelectBox 컴포넌트와 유사한 외관을 갖추고 있으면서도 단일 선택에 국한되지 않고 복수의 선택을 가능하게 한다는 점이 큰 차별점입니다. 이 컴포넌트를 사용하면 개발자는 선택 가능한 옵션들을 시각적으로 표시하고, 사용자가 원하는 항목을 복수 개로 선택할 수 있도록 손쉽게 구현할 수 있습니다.

2주요 용도 및 특징

MultiSelect 컴포넌트는 다음과 같은 상황에서 주로 활용됩니다.

다중 선택이 필요한 폼

사용자가 여러 개의 카테고리, 태그, 관심사 등을 선택해야 하는 경우에 적합합니다.

필터링 및 검색

데이터 목록에서 여러 개의 필터를 동시에 적용하거나, 여러 검색어를 선택하여 결과를 좁히는 데 사용할 수 있습니다.

권한 설정

사용자에게 여러 개의 권한을 부여하거나, 그룹에 여러 개의 기능을 할당할 때 유용합니다.

설문 조사

응답자가 여러 개의 답변을 선택할 수 있는 설문 항목을 구성하는 데 활용될 수 있습니다.
