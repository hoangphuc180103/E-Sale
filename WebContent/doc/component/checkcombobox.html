CheckComboBox

1소개

CheckComboBox 컴포넌트는 체크박스와 드롭다운 리스트가 결합된 형태의 다중 선택 컴포넌트로, 사용자가 여러 항목을 선택할 수 있도록 체크박스와 목록을 결합한 형태의 UI를 제공하는 컴포넌트입니다. CheckComboBox는 드롭다운 메뉴 형태로 선택 항목 목록을 표시하며, 각 항목 앞에 체크박스를 배치하여 사용자가 원하는 항목을 체크하는 방식으로 다중 선택이 가능합니다. 선택된 항목들은 컴포넌트의 표시 영역에 나열되어 사용자가 자신의 선택 내용을 쉽게 확인할 수 있습니다.

2주요 용도 및 특징

CheckComboBox는 다음과 같은 상황에서 특히 유용하게 활용됩니다.

다중 선택이 필요한 경우

사용자가 여러 옵션을 동시에 선택해야 하는 폼 요소로 활용할 수 있습니다.

공간 효율성이 중요한 UI

여러 체크박스를 나열하는 대신 드롭다운 형태로 제공하여 화면 공간을 효율적으로 사용할 수 있습니다.

카테고리 필터링

데이터 필터링이나 검색 조건 설정 시 여러 카테고리를 선택할 수 있도록 합니다.

설정 인터페이스

다양한 옵션을 활성화/비활성화할 수 있는 설정 메뉴를 구현할 때 적합합니다.

3주요 기능

  • 선택 항목 설정

    • 직접 입력 방식 (YouTube)

    • DataList와 바인딩 (샘플, YouTube)

    • 선택 항목 동적 설정 (WRE)

    • 선택 항목 정보 반화 (WRE)

  • Label 및 Value 표시

    • 정적 설정 (샘플, YouTube)

    • 동적 설정 (샘플, YouTube)

    • 구분자 동적 설정 (WRE, 샘플, YouTube)

  • 항목 제어

    • 항목 선택 및 선택 해지 (WRE)

    • 일부 항목 숨기기 (WRE, 샘플, YouTube)

    • 일부 항목 비활성화 (WRE)

      • 정적 비활성화 (샘플, YouTube)

      • 동적 비활성화 (샘플, YouTube)

  • 선택 항목 목록 표시 방식 설정

    • 열 개수 설정 (WRE, 샘플, YouTube)

    • 최대 열 개수 설정 (샘플, YouTube)

    • 표시할 행의 개수 설정 (WRE, 샘플, YouTube)

    • 선택 항목 목록 너비 설정 (샘플, YouTube)

    • 말 줄임표 표시 (샘플, YouTube)

    • 선택된 항목을 목록 상단에 표시 (WRE, 샘플, YouTube)

  • UI 사용성 향상 기능

    • 선택완료 및 선택해제 버튼 (YouTube)

    • 전체 선택 옵션 및 선택 안내 메시지 (YouTube)

  • 툴팁

    • 선택된 항목 툴팁 – tooltipDisplay="true"

    • 항상 툴팁 표시 – tooltipShowAlways="true"

    • 툴팁 표시 시간 – tooltipTime

    • 목록 항목 툴팁 – itemTooltipDisplay="true"

    • 사용자 정의 툴팁 – itemTooltipFormatter

  • 입력 시 검증 (샘플, YouTube)

  • 기타

    • 마우스 드래깅을 통한 연속된 값 선택 (WRE, 샘플, YouTube)

    • 연속된 선택 항목을 축약 표시 (WRE)

    • 연속된 선택 항목들이 선택된 경우 출력하기 (WRE)

    • 키보드 입력을 통한 선택 허용 (WRE, 샘플, YouTube)
