SelectBox

1소개

SelectBox 컴포넌트는 사용자가 미리 정해진 항목 중에서 하나를 선택할 수 있도록 목록 형태로 제공하는 UI 요소입니다. 웹 화면에서 SelectBox의 화살표 버튼을 클릭하면 선택 가능한 항목 목록이 표시되며, 사용자는 원하는 항목을 선택할 수 있습니다. 일반적으로 콤보 박스라고도 불리며, 사용자가 버튼을 클릭하면 선택 가능한 항목 목록이 펼쳐지고, 이 중 하나를 선택하면 해당 항목이 입력란에 표시됩니다. 이 컴포넌트는 단일 선택만 허용하며, 드롭다운 리스트 형태로 구성됩니다.

2주요 용도 및 특징

SelectBox 컴포넌트는 다음과 같은 상황에서 특히 유용합니다:

제한된 선택지 제공

사용자가 미리 정의된 옵션 중 하나를 선택해야 하는 경우 유용합니다. (예: 국가 선택, 카테고리 선택)

데이터 검증 필요

사용자 입력을 제한하여 유효한 값만 선택되록 할 때 유용합니다.

연관된 필드 제어

한 필드의 선택에 따라 다른 필드의 옵션이 변경되어야 할 때 (예: 대륙 → 국가 → 도시) 사용할 수 있습니다.

3주요 기능

  • 선택 항목 설정

    • 직접 입력 (YouTube)

    • DataList와 바인딩 (WRE, 샘플, YouTube)

    • 컴포넌트의 값( value )과 데이터 객체(DataMap, DataList) 연결 (WRE)

  • 계층 구조의 선택 항목 표시 (WRE)

    • 데이터 설정 (샘플, YouTube)

    • 상위 항목 표시 (샘플, YouTube)

    • 목록의 높이 및 너비 설정 (샘플, YouTube)

  • 선택 항목

    • 선택 항목 표시 (WRE)

    • 표시할 행의 개수 설정 (샘플, YouTube)

    • 목록 너비 자동 조절 (WRE, 샘플, YouTube)

    • 일부 선택 항목 숨기기 (WRE, 샘플, YouTube)

    • 일부 선택 항목 비활성화 (WRE)

      • 정적 설정 (샘플, YouTube)

      • 동적 설정 (샘플, YouTube)

  • label 및 value 표시 설정

    • 정적 설정 (샘플, YouTube)

    • 동적 설정 (샘플, YouTube)

    • 구분자 동적 설정 (샘플, YouTube)

  • 마우스 휠 스크롤링

    • 선택 목록 상에서 스크롤링 방지 1 (YouTube)

    • 선택 목록 상에서 스크롤링 방지 2 (YouTube)

  • 입력 검증 및 오류 메시지 표시 (WRE, 샘플, YouTube)

  • 툴팁

    • 선택 목록 혹은 항목 위에 툴팁 표시 (WRE, 샘플, YouTube)

    • 툴팁 커스터마이징 (샘플, YouTube)

  • 기타

    • 특정 키 동작 방지 (WRE, 샘플, YouTube)

    • 목록에 없는 값의 처리 (WRE, 샘플, YouTube)

    • disabled 상태일 때 적용할 CSS class 설정 (WRE)

    • optionOrder 속성을 사용하여 선택 항목과 전체 항목의 표시 순서 설정 (WRE)

    • renderType에 따른 비교 (WRE)

    • 속성을 사용하여 전체 항목 표시 (WRE)

4주요 이벤트

  • onbeforeselect (샘플)

  • onselected (WRE, 샘플, YouTube)

5AutoComplete vs. SelectBox

AutoComplete와 SelectBox는 모두 선택 항목을 목록 형태로 제공하는 컴포넌트이지만, 몇 가지 주요 차이점이 있습니다. (YouTube)

공통점

콤보 박스 형태로 선택 항목을 표시합니다.

사용자는 단일 항목만 선택할 수 있습니다.

차이점

AutoComplete는 검색 기능을 제공합니다.

사용자가 키워드 입력 시 해당 키워드를 포함하는 항목만 필터링하여 표시합니다.

대소문자 구분, 키워드 강조 등의 추가 기능을 제공합니다.
