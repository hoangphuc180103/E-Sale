Spinner

1소개

Spinner 컴포넌트는 사용자가 화살표 버튼 또는 직접 입력을 통해 숫자나 날짜, 시간 등의 값을 간편하게 조절할 수 있도록 도와주는 UI 요소입니다. 입력 필드와 증감 버튼을 결합한 형태로, 다양한 유형의 값 증가 단위를 설정할 수 있어 효율적인 데이터 입력을 지원합니다. 웹스퀘어 AI의 Spinner는 단순한 숫자 입력뿐만 아니라 날짜(Date) 및 시간(Time) 입력까지 확장 가능하며, 사용자는 입력 필드 옆에 상하 화살표를 제공하여 값을 증가시키거나 감소시킬 수 있으며, 직접 값을 입력할 수도 있습니다. Spinner는 사용자가 키보드로 직접 입력하는 방식보다 오류 발생 가능성을 줄여주며, 특히 모바일 환경에서 손가락으로 쉽게 조작할 수 있어 사용자 경험을 향상시킵니다.

2주요 용도 및 특징

Spinner 컴포넌트는 다음과 같은 상황에서 유용하게 사용될 수 있습니다.

수량 입력

제품 수량, 인원 수 등 정수 값을 입력할 때 사용자가 쉽게 값을 조정할 수 있습니다.

날짜 선택

연, 월, 일 단위로 날짜를 선택할 때 사용자가 직관적으로 날짜를 조절할 수 있습니다.

시간 설정

시, 분, 초 단위로 시간을 설정할 때 사용자가 쉽게 시간을 조정할 수 있습니다.

범위가 정해진 값 선택

최소값과 최대값 사이에서 특정 값을 선택해야 할 때 유용합니다.

단계적 값 조정

특정 증감 단위로 값을 조정해야 할 때 사용할 수 있습니다.

직관적인 값 조절

상하 화살표를 통해 값을 직관적으로 조절할 수 있어 사용자 편의성을 높입니다.

3주요 기능

  • 데이터 타입 설정 (WRE)

  • 증감 단위 설정

    • 날짜 증가 단위 (WRE, 샘플, YouTube)

    • 시간 증가 단위 (WRE, 샘플, YouTube)

  • 초기 값 지정 (WRE, 샘플, YouTube)

  • 자동 포커스 이동 (샘플, YouTube)

  • 잘못 입력한 날짜에 대한 경고 출력 (WRE, 샘플, YouTube)

  • HTML의 <title> 태그 지원 (샘플, YouTube)
