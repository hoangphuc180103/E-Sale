팝업

1소개

WebSquare AI의 팝업 시스템은 $p.openPopup() 함수를 통해 생성되는 강력하고 유연한 윈도우 관리 솔루션입니다. 이 시스템은 현대적인 웹 애플리케이션에서 요구되는 다양한 사용자 인터페이스 패턴을 지원하며, 복잡한 비즈니스 로직과 사용자 상호작용을 효과적으로 처리할 수 있도록 설계되었습니다.

WebSquare AI의 팝업은 단순한 알림창을 넘어서 완전한 기능을 갖춘 독립적인 윈도우로 작동하며, 부모-자식 관계를 통한 계층적 구조, 스코프 기반의 데이터 공유, 그리고 다양한 프레임 타입을 통한 유연한 렌더링을 제공합니다. 이러한 특징들은 엔터프라이즈급 애플리케이션 개발에 필요한 확장성과 유지보수성을 보장합니다.

2주요 용도 및 특징

팝업은 단순한 알림 창이나 추가 입력, 세부 정보 제공 등의 역할을 수행할 뿐만 아니라 다음과 같은 다양한 용도로 사용할 수 있습니다.

정보 표시

사용자에게 중요한 알림, 경고, 또는 추가 정보를 일시적으로 표시할 때 사용됩니다.

사용자 입력

복잡한 폼이나 상세 정보를 입력받을 때 별도의 팝업 윈도우를 통해 사용자의 집중도를 높이고 주 화면의 컨텍스트를 유지할 수 있습니다. 특히 마스터-디테일 관계의 데이터를 다룰 때 효과적입니다.

데이터 선택

주소 검색, 달력에서 날짜 선택 등과 같이 특정 데이터를 선택하고 부모 창으로 반환해야 할 때 사용됩니다.

워크플로우 관리

복잡한 작업 흐름을 여러 단계의 팝업으로 나누어 사용자에게 명확한 가이드라인을 제공할 수 있습니다.

리포팅 및 대시보드

상세 분석 결과나 드릴다운 데이터를 별도 팝업에서 표시하여 주 화면의 개요와 상세 정보를 동시에 제공할 수 있습니다.

  • 팝업 생성 및 유형

    • PageFrame 팝업 활용 (샘플, YouTube)

    • 팝업 생성 시 파라미터 전달 (샘플, YouTube)

  • 모달 팝업

    • 모달 팝업 Vs. 모달리스 팝업 (WRE)

    • 프레임 기반 모달 팝업 생성 (샘플, YouTube)

  • 팝업 여부 확인

    • 팝업 여부 확인 (샘플)

    • WFrame 팝업 여부 확인 (샘플, YouTube)

  • 팝업 간 상호 작용 및 데이터 전달

  • 부모의 Scope 상속 (샘플)

  • 팝업 여부 확인 (WRE, YouTube)

  • 팝업 반환 및 접근

    • 전체 팝업 객체 반환 (샘플, YouTube)

    • 개별 팝업 윈도우 반환 및 접근 (샘플)

  • 팝업 닫기 및 생명 주기 관리

    • 부모 팝업만 닫기 (샘플)

    • 부모-자식 팝업 함께 닫기

      • WFame에서 부모-자식 팝업 함께 닫기 (샘플, YouTube)

  • 팝업 표시

    • 팝업 위치 고정 (WRE, 샘플, YouTube)

    • 팝업 크기 기반 적응형 디자인 적용 (샘플, YouTube)
