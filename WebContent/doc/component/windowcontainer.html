WindowContainer

1소개

WindowContainer는 웹스퀘어 AI에서 여러 개의 윈도우를 생성하고 관리할 수 있도록 지원하는 컨테이너 컴포넌트입니다. MDI(Multiple Document Interface) 방식을 활용하여 부모-자식 관계의 윈도우를 계층적으로 구성할 수 있으며, 동적 윈도우 생성, 고정, 정렬, 최소화 및 최대화 등 다양한 윈도우 제어 기능을 제공합니다. WindowContainer를 사용하면 툴바에서 여러 윈도우를 손쉽게 제어할 수 있으며, 동적 데이터 전달, 윈도우 고정, 최소화 및 최대화 기능 등 다양한 기능을 사용할 수 있습니다.

2주요 용도 및 특징

WindowContainer는 주로 다음과 같은 상황에서 활용됩니다:

다중 작업 환경 구축

여러 개의 화면이나 애플리케이션을 동시에 사용자에게 제공해야 할 때 유용합니다. 예를 들어, 대시보드 형태의 화면에서 여러 통계 창을 동시에 띄우거나, 한 화면에서 여러 문서 편집 창을 열어야 할 때 사용될 수 있습니다.

복잡한 데이터 조회 및 편집

관련 데이터를 여러 윈도우에 분산하여 표시하고, 각 윈도우에서 독립적으로 데이터를 조회하거나 편집할 수 있도록 지원합니다.

모듈화된 UI 구성

개별적인 기능 단위를 윈도우 형태로 모듈화하여, 사용자가 필요한 기능만 선택적으로 열고 닫을 수 있도록 합니다. 이는 애플리케이션의 유연성과 확장성을 높이는 데 기여합니다.

사용자 경험 개선

사용자가 원하는 방식으로 윈도우를 배치하고 크기를 조절할 수 있게 하여, 개인화된 작업 환경을 제공하고 전반적인 사용자 만족도를 향상시킵니다.
