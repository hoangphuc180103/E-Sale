PageList

1소개

PageList 컴포넌트는 방대한 양의 데이터를 여러 페이지로 나누어 표시할 때 사용되는 페이지네이션(Pagination) 기능을 제공합니다. PageList 컴포넌트는 사용자가 전체 데이터를 한눈에 볼 수 있도록 페이지 단위로 데이터를 탐색하고, 원하는 페이지로 쉽고 빠르게 이동할 수 있도록 도와줍니다. 또한, 페이지 번호, 페이지 목록, 그리고 다양한 네비게이션 버튼 등을 통해 페이지 전환을 직관적으로 지원하며, 사용자 경험(UX)을 높이는데 기여합니다.

2주요 용도 및 특징

PageList는 주로 다음의 목적을 위해 사용됩니다.

페이지 번호 및 페이지 목록 표시

현재 페이지와 전체 페이지 수를 시각적으로 구분하여 표시합니다.

페이지 선택 인터페이스 제공

사용자가 직접 페이지 번호를 입력하거나 버튼을 클릭하여 원하는 페이지로 이동할 수 있도록 합니다.

네비게이션 버튼 구성

이전/다음 페이지 및 목록 이동 버튼 등 다양한 버튼 타입을 제공하여 상황에 맞는 페이지 이동 방식을 지원합니다.

3주요 기능

  • 총 페이지 수 설정 (WRE)

  • 페이지 숫자 사이에 구분자 사용 (WRE)

  • 페이지 이동 버튼 설정 (WRE)

  • 페이지 검색 (WRE, YouTube)

  • GridView와 연계 (WRE)

  • 남은 페이지 표시 유형 설정 (WRE)

  • 브라우저에 렌더링할 때, <table> 또는 <ul> 태그로 구성 (WRE)
