Secret

1소개

Secret 컴포넌트는 웹 화면에서 사용자가 입력한 텍스트를 일반적인 텍스트가 아닌 지정된 별도의 기호로 마스킹하여 표시하는 보안성이 강화된 입력 상자입니다. 기본적으로 InputBox 컴포넌트의 기능을 모두 제공하면서도 보안성을 높인 텍스트 입력 방식을 제공합니다. 이 컴포넌트를 사용하면 사용자의 중요한 정보, 예를 들어 비밀번호나 개인 식별 정보 등을 안전하게 처리할 수 있습니다.

Secret 컴포넌트를 통해 입력되는 데이터는 화면상으로는 마스킹 처리되어 보이지만, 실제 데이터는 그대로 유지되어 서버로 전송되거나 애플리케이션 내에서 처리될 수 있습니다.

HTML5의 <input type="password"> 에서도 유사한 기능을 제공하며, WebSquare AI는 이에 더해 검증 메시지, 커스터마이징 가능한 마스킹 문자 등 고급 기능을 지원합니다.

2주요 용도 및 특징

Secret 컴포넌트는 다음과 같은 상황에서 주로 활용됩니다:

비밀번호 입력

로그인, 회원가입, 비밀번호 변경 등의 화면에서 비밀번호를 입력받을 때 사용합니다.

개인식별번호(PIN) 입력

금융 거래나 보안 인증이 필요한 시스템에서 PIN 번호를 입력받을 때 활용할 수 있습니다.

보안 코드 입력

2단계 인증 또는 일회용 비밀번호(OTP) 등의 보안 코드를 입력받는 경우에 사용합니다.

민감한 개인정보 입력

주민등록번호, 신용카드 번호 등 노출 시 개인정보 유출 위험이 있는 정보 입력 시 활용할 수 있습니다.

보안이 중요한 데이터 입력

그 외 보안이 중요한 데이터를 입력받을 때, 입력 내용을 보호하기 위해 사용될 수 있습니다.

3주요 기능

  • 입력 검증 기능

    • 필수 입력 검증 – mandatory

    • 길이 제한 – minlength , maxlength

    • 바이트 길이 제한 – minByteLength , maxByteLength

  • 입력 검증 및 오류 메시지 표시 (샘플, YouTube)

  • 읽기 전용 모드 – readOnly

  • 비활성화 – disabled

  • 데이터 형식 지정 – dataType
