Editor

1소개

Editor 컴포넌트는 웹 화면에서 텍스트 편집 기능을 손쉽게 구현할 수 있도록 도와주는 UI 구성 요소입니다. CKEditor를 기반으로 하며, 상용 문서 편집 프로그램과 유사한 문서 편집 경험을 웹 애플리케이션 내에서 제공합니다. 개발자는 Editor 컴포넌트는를 화면에 추가하는 것만으로 강력한 웹 에디터를 구축할 수 있습니다.

2주요 용도 및 특징

Editor 컴포넌트는 웹 애플리케이션에서 다음과 같은 다양한 용도로 활용될 수 있습니다.

콘텐츠 작성 및 편집

게시판, 블로그, CMS(콘텐츠 관리 시스템) 등에서 사용자가 텍스트 기반의 콘텐츠를 작성하고 편집하는 데 활용됩니다.

서식 있는 텍스트 입력

텍스트의 스타일(굵게, 기울임, 밑줄 등), 글꼴, 크기, 색상 등을 지정하여 서식 있는 텍스트를 입력받는 데 사용됩니다.

HTML 편집

HTML 코드를 직접 편집하고 미리 볼 수 있는 기능을 제공하여 웹 페이지의 레이아웃이나 스타일을 동적으로 변경하는 데 활용될 수 있습니다.

데이터 입력 및 처리

사용자가 입력한 텍스트 데이터를 특정 형식으로 처리하거나, 다른 시스템과 연동하는 데 사용됩니다.

3주요 기능

  • 최대 입력 글자수 지정 (샘플, YouTube)

  • Placeholder 설정 (샘플, YouTube)

  • 입력된 텍스트 반환 방법

    • 개행 문자를 포함하여 텍스트 반환 (샘플, YouTube)

    • 개행 없이 텍스트만 반환 (샘플, YouTube)

    • HTML 태그와 텍스트 모두 반환 (샘플, YouTube)

  • 에디터 내용 설정

    • HTML 형식으로 내용 설정 – setHTML()

    • 텍스트만 설정 – setText()

  • 에디터 활성화/비활성화 – setDisabled()

  • 에디터 크기 조절 – setSize()
