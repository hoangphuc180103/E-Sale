Pivot

1소개

Pivot 컴포넌트는 기존 GridView에서 제한적으로 제공되던 피벗 기능을 전문적으로 지원하는 구성 요소입니다. Excel의 피벗 테이블과 유사한 기능을 제공하여 다차원 데이터 분석은 물론, 드릴다운, 축 변환, 무한한 가로 스크롤링 등 다양한 기능을 직관적으로 사용할 수 있도록 설계되었습니다. 또한, 통계 함수(합계, 평균, 개수, 최소, 최대)를 비롯해 사용자 정의 함수에 의한 커스터마이징이 가능하며, 다양한 데이터 바인딩 및 포매팅 옵션을 통해 복잡한 데이터 분석 요구를 만족합니다. IE10 이상의 브라우저에서 안정적으로 동작함으로써 다양한 환경에서 활용할 수 있습니다.

2주요 용도 및 특징

Pivot 컴포넌트는 주로 다음과 같은 용도로 사용됩니다.

데이터 분석 및 보고서 작성

대량의 데이터를 요약하고 특정 기준에 따라 집계하여 비즈니스 보고서나 분석 자료를 생성할 때 유용합니다.

다차원 데이터 시각화

다차원 데이터를 시각적으로 분석하여 의사결정에 필요한 정보를 제공하며, 여러 필드를 기준으로 데이터를 교차 분석하여 인사이트를 도출하고 시각적으로 표현할 때 효과적입니다.

사용자 정의 가능한 데이터 뷰

사용자가 직접 컬럼을 재배치하거나 필터링하여 자신에게 맞는 데이터 뷰를 생성하고 저장할 수 있도록 지원합니다.

비즈니스 인텔리전스

드릴다운 기능과 축 변환을 통해 사용자가 원하는 데이터를 자유롭게 재구성할 수 있어, 복잡한 데이터 집합을 분석하는 데 효과적입니다.

파일 입출력

Excel 및 CSV 파일을 통한 데이터 내보내기와 업로드 기능을 제공하여, 다른 시스템과의 데이터 연동 및 리포팅 업무에 활용 가능합니다.

3주요 기능

  • 헤더 컬럼 병합 (샘플, YouTube)

  • 컬럼 이동 금지 (WRE, 샘플, YouTube)

  • 합계

    • 총 합계 표시하기/숨기기 (샘플, YouTube)

    • 총 합계 표시 위치 설정 (샘플, YouTube)

    • 행 합계 및 컬럼 합계를 표시할 라벨 값을 설정 (샘플)

    • 필드 합계를 표시할 라벨 값을 커스텀 설정 (샘플)

  • Excel 파일 연동

    • Pivot → Excel 다운로드 (샘플, YouTube)

    • (컬럼 너비 자동 조절한 상태로) Pivot → Excel 다운로드 (WRE, 샘플, YouTube)

    • (헤더 컬럼 병합하여) Pivot → Excel 다운로드 (WRE, 샘플, YouTube)

    • Excel → Pivot 업로드 (샘플, YouTube)
