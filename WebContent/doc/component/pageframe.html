PageFrame

1소개

PageFrame 컴포넌트는 WebSquare AI에서 제공하는 화면 분할 및 로딩용 UI 컴포넌트입니다. 기존 WFrame과 동일한 기능을 제공하며, 추가적으로 Page Component를 소스( src ) 로 지정하여 해당 Page Component의 API에 직접 접근할 수 있는 기능을 제공합니다. 이로 인해 복잡한 사용자 정의 컴포넌트(UDC)를 별도로 등록하지 않고도 재사용 가능한 구조를 손쉽게 구성할 수 있고, 복잡한 애플리케이션을 모듈화하고 각 모듈을 독립적으로 개발 및 배포할 수 있어 개발 효율성을 높일 수 있습니다.

2주요 용도 및 특징

PageFrame은 다음과 같은 상황에서 효과적으로 활용할 수 있습니다.

모듈화된 화면 개발

복잡한 애플리케이션을 여러 개의 독립적인 Page Component로 분할하여 개발할 때 각 모듈을 PageFrame으로 통합 관리할 수 있습니다.

재사용 가능한 컴포넌트 구현

공통으로 사용되는 화면 요소들을 Page Component로 작성하고, PageFrame을 통해 다양한 화면에서 재사용할 수 있습니다.

복잡한 레이아웃 관리

하나의 페이지 내에 여러 개의 독립적인 영역을 구성해야 할 때, 각 영역을 PageFrame으로 분리하여 관리함으로써 페이지의 복잡성을 줄이고 가독성을 높일 수 있습니다.

동적 컨텐츠 로딩

사용자의 상호작용이나 비즈니스 로직에 따라 다른 화면을 동적으로 로딩해야 하는 경우에 활용할 수 있습니다.

기존 WFrame 대체

WFrame을 사용하던 기존 프로젝트에서 더 향상된 기능이 필요한 경우 PageFrame으로 원활하게 마이그레이션할 수 있습니다.

복합 UI 구성

TabControl, WindowContainer, 팝업 등 다른 컨테이너 컴포넌트와 함께 사용하여 복잡한 사용자 인터페이스를 구성할 수 있습니다.

3주요 기능

  • Page Component의 메소드 사용 (샘플, YouTube)

  • Page Component를 소스 화면으로 연결 (WRE)

  • WFrame 호환 및 대체
