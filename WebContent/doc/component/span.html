Span

1소개

Span 컴포넌트는 HTML의 <span> 태그와 유사한 역할을 하는 웹스퀘어 AI의 텍스트 출력 전용 UI 컴포넌트입니다. 웹 페이지 내에서 텍스트 데이터를 표시하기 위한 기본적인 컴포넌트로, 특히 인라인 요소로서 다른 컴포넌트들과 함께 사용할 때 유용합니다. 기본적으로 출력 기능만을 제공하며, 사용자 입력은 허용하지 않습니다. tagname 속성이 "span" 으로 설정된 TextBox 컴포넌트로 구현되며, Output 컴포넌트와 동일한 방식으로 사용할 수 있습니다.

Span은 가볍고 간단한 텍스트 출력이 필요한 곳에 적합하며, 텍스트를 스타일링하거나 구간별로 데이터를 시각적으로 구분하는 데에 유용합니다. 특히 UI 요소 간 간격을 조절하거나 레이블과 텍스트를 함께 배치할 때 유용하게 사용됩니다.

2주요 용도 및 특징

Span 컴포넌트는 다음과 같은 상황에서 주로 사용됩니다.

웹 브라우저 전체 폭에 걸쳐 문자열을 출력

Span 컴포넌트는 웹 페이지 레이아웃에서 텍스트를 유연하게 표시할 수 있습니다. 특히 전체 화면 폭을 활용하여 텍스트를 출력하고자 할 때 유용합니다.

인라인 텍스트 요소로 사용

다른 UI 요소들과 함께 한 줄에 배치하여 사용할 수 있습니다. 이는 레이블, 설명 텍스트, 또는 동적으로 변경되는 값을 표시할 때 편리합니다.

스타일 적용이 필요한 특정 텍스트 영역에 사용

CSS를 통해 특정 텍스트 부분에만 스타일을 적용하고자 할 때 Span 컴포넌트를 활용할 수 있습니다.

폼 레이아웃 내에서 라벨이나 값 표시

폼 요소의 라벨이나 읽기 전용 값을 표시할 때 주로 사용됩니다.

3주요 기능

  • 텍스트 표시

  • 스타일 적용

  • 데이터 타입 설정 (WRE)
