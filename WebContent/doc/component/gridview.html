GridView

1소개

GridView는 테이블 형태의 데이터를 효율적으로 표시하고 조작할 수 있는 웹스퀘어 AI의 핵심 UI 컴포넌트입니다. 기본적으로 Body와 Header, 그리고 Footer로 구분되어 있으며, 별도의 소계(SubTotal) 기능을 통해 특정 컬럼의 통계 데이터를 계산하여 표시할 수 있습니다. 복잡한 데이터 구조를 직관적인 그리드 형태로 제공하여 사용자가 데이터를 쉽게 탐색하고 편집할 수 있도록 지원합니다. GridView는 DataList (DataCollection)와 바인딩되어 데이터를 처리하며, 다양한 데이터 형식 지원, 자유로운 그리드 편집, 페이징, 정렬, 필터링, 그룹핑 등 폭넓은 기능을 제공합니다. 특히, 순차적인 데이터 표시와 무한 스크롤링을 통해 대용량 데이터 처리 시에도 뛰어난 출력 속도와 성능을 보장하는 것이 특징입니다.

2주요 용도 및 특징

GridView는 다음과 같은 시나리오에서 특히 유용하게 활용될 수 있습니다.

복잡한 테이블 구성

다양한 데이터 형식과 복잡한 레이아웃이 필요한 테이블을 구성할 때 GridView의 유연한 inputType 및 셀 병합 기능이 효과적으로 활용될 수 있습니다. 또한 컬럼과 행 병합, Header 병합 기능 등을 통해 복잡한 데이터 구조를 명확하게 표현할 수 있습니다.

대량의 데이터 처리

수십만 건 이상의 데이터를 조회, 편집, 분석해야 하는 환경에서 GridView의 순차적인 데이터 표시 및 무한 스크롤링 지원 기능은 대용량 데이터의 출력 속도를 개선하고 향상된 사용자 경험을 제공합니다.

대용량 파일 업로드/다운로드

Excel, CSV, 한셀/넥셀 등 대용량 파일과의 연동 기능을 통해 데이터 가져오기/내보내기 기능을 구현할 때 유용합니다.

데이터 기반 보고서 및 대시보드

실시간 데이터 변동을 반영하거나, 통계 및 요약 정보가 필요한 보고서 및 대시보드 화면 구성에 GridView의 subTotal 및 footer 기능이 적합합니다. 이를 통해 사용자는 데이터를 시각적으로 분석하고 중요한 비즈니스 지표를 한눈에 파악할 수 있습니다.

실시간 데이터 바인딩

DataList와의 연동을 통해 실시간으로 데이터가 갱신되도록 할 수 있으며, 클립보드 및 드래그 앤 드롭 기능을 활용해 빠른 데이터 처리가 가능합니다.
