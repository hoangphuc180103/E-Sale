FloatingLayer

1소개

FloatingLayer는 웹 애플리케이션에서 화면 안에 팝업 형태로 출력되는 새로운 창을 생성하는 UI 컴포넌트입니다. 본 컴포넌트는 화면의 최상위 층에 출력되며, 모달 창으로 출력될 수도 있습니다. 이는 사용자에게 특정 정보나 기능을 부각하여 제공할 때 유용하며, 일반적인 팝업 창과 유사한 기능을 하지만 웹 페이지 내에 독립적으로 존재하며 이동 및 크기 조절이 가능한 특징을 가집니다.

2주요 용도 및 특징

정보 표시

특정 요소에 대한 상세 정보(예: 상품 정보, 사용자 프로필 등)를 별도의 레이어에 표시하여 사용자의 집중도를 높일 수 있습니다. 그림 11은 해리포터 책의 정보를 FloatingLayer로 표시하는 예시를 보여줍니다.

알림 및 경고

사용자에게 중요한 알림이나 경고 메시지를 표시하여 즉각적인 확인을 유도할 수 있습니다.

도구 모음

자주 사용되는 기능들을 FloatingLayer에 모아 사용자에게 편리한 접근성을 제공할 수 있습니다.

사용자 인터랙션

드래그 앤 드롭과 같은 사용자 인터랙션을 통해 레이어를 자유롭게 이동시키며 정보를 탐색할 수 있도록 지원합니다.

3주요 기능

  • 리사이징 (WRE)

  • 이동 제어

    • 위치 고정 (WRE)

    • PageFrame 외부로의 이동 제어 (샘플, YouTube)

  • 닫기 버튼 사용 여부 설정 (샘플, YouTube)

  • 헤더 영역에 타이틀 설정 (WRE)

  • 브라우저 제목 연동 – documentTitle
