TabControl

1소개

TabControl은 웹 애플리케이션에서 다중 화면을 탭 형태로 관리할 수 있는 강력한 UI 컴포넌트입니다. 사용자는 TabControl을 통해 단일 화면에서 여러 탭을 오가며 다양한 정보를 확인하거나 작업을 수행할 수 있어, 사용자 경험을 향상시키고 복잡한 인터페이스를 간결하게 만듭니다. 각 탭은 별도의 화면 파일( src )을 로드할 수 있어 독립적인 콘텐츠와 기능을 제공합니다. TabControl은 iframe , wframe , wframePreload , pageFrame 의 프레임 모드를 지원하며, 각 모드는 객체 참조나 성능에 따라 구분됩니다.

2주요 용도 및 특징

TabControl은 다음과 같은 다양한 상황에서 활용됩니다.

폼 양식 구성

복잡한 입력 폼을 여러 단계나 카테고리로 나누어 사용자의 입력 부담을 줄이고 직관적인 인터페이스를 제공합니다. 예를 들어, 회원가입 폼을 개인정보, 연락처, 추가정보 탭으로 구분하여 단계별 입력을 가능하게 합니다.

대시보드 및 관리 화면

관리자 화면에서 다양한 기능들을 탭으로 구분하여 효율적인 화면 관리를 제공합니다. 사용자 관리, 시스템 설정, 통계 분석 등을 별도의 탭으로 구성하여 업무 효율성을 높입니다.

문서 관리 시스템

여러 문서나 파일을 동시에 열어 작업할 때 탭 형태로 관리하여 빠른 전환과 비교 작업을 지원합니다.

설정 및 환경설정 화면

애플리케이션의 다양한 설정 옵션들을 카테고리별로 분류하여 사용자가 쉽게 찾고 수정할 수 있도록 합니다.

데이터 뷰어

동일한 데이터를 다양한 형태(그래프, 테이블, 차트)로 표시할 때 각각을 별도의 탭으로 구성하여 사용자가 원하는 형태로 데이터를 확인할 수 있게 합니다.

3주요 기능

  • 탭 생성 – addTab()

    • alwaysDraw 설정 (WRE)

    • openAction 설정 (WRE)

    • 탭 소스 동적 변경 – getFrame().setSrc()

    • 탭 생성 시 파라미터 전달 (샘플, YouTube)

    • 부모의 Scope 상속 (샘플)

    • PageFrame 탭 생성 (샘플, YouTube)

  • 탭 선택

    • 초기 탭 선택 (WRE)

    • 탭의 Index로 탭 선택 (WRE)

    • Tab 키로 다음 탭으로 이동 (WRE)

  • 탭 관리

    • 탭의 ID로 Index 반환 (WRE)

    • 선택된 탭의 ID 또는 Index 반환 (WRE)

    • 탭 정보 반환 (WRE)

    • 자식 탭의 비활성화 상태 유지 (WRE, 샘플, YouTube)

    • 탭의 컨텐츠에 구성된 컴포넌트의 메소드 호출 (WRE)

    • 마우스 드래깅으로 탭 순서 변경 (WRE)

  • 팝업

    • 탭에서 생성한 부모-자식 팝업 함께 닫기 (샘플, YouTube)

    • 탭 내부에서 프레임 기반 모달 팝업 생성 (샘플, YouTube)

  • 탭 스크롤

    • 탭의 이동 버튼의 기능 설정 (WRE)

    • 탭을 닫을 때 스크롤에 보이는 탭의 수를 유지 (WRE, 샘플, YouTube)

    • 탭 스크롤 위치 설정 (샘플, YouTube)

    • 스크롤 버튼으로 탭 선택 (샘플, YouTube)

  • 적응형 디자인 및 상태창

    • 적응형 디자인 적용 (샘플)

  • 서브미션 상태창 표시

    • 기본 상태창 (샘플, YouTube)

    • 커스텀 상태창 (샘플, YouTube)

  • 탭 UI 설정

    • 탭의 기능(탭 이동, 목록 보기) 버튼 사용 설정 (WRE)

    • 탭 위치 설정 (WRE, 샘플, YouTube)

    • 탭 닫기 버튼 표시 (샘플, YouTube)

    • 탭 선택 상태를 툴팁으로 표시 (샘플, YouTube)
