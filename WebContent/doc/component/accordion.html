Accordion

1소개

Accordion 컴포넌트는 여러 개의 패널로 구성되어, 각 패널에 서로 다른 컨텐츠를 담아 순차적으로 열고 닫을 수 있는 UI 구성 요소입니다. 각 패널은 제목(헤더)과 내용(콘텐츠)으로 구성되어 있으며, 사용자는 제목을 클릭하여 해당 패널의 내용을 열거나 닫을 수 있습니다. 이 컴포넌트는 콘텐츠를 효율적으로 구성하고, 사용자가 원하는 특정 패널의 내용을 확장하거나 축소하여 정보를 보기 쉽게 제공하여 사용자 인터페이스의 가독성과 편의성을 높이는 데 활용됩니다.

2주요 용도 및 특징

Accordion 컴포넌트는 다음과 같은 상황에서 유용하게 사용될 수 있습니다.

정보 분류 및 계층화

많은 양의 정보를 논리적인 그룹으로 묶어 보여줄 때 효과적입니다. 예를 들어, 자주 묻는 질문(FAQ) 목록, 설정 옵션, 제품 상세 정보 등을 분류하여 표시할 수 있습니다.

공간 효율성 증대

한정된 화면 공간에서 다양한 콘텐츠를 제공해야 할 때, Accordion은 콘텐츠를 접어서 숨겨 공간을 절약할 수 있습니다.

사용자 상호작용 개선

사용자가 원하는 섹션만 열어볼 수 있도록 하여, 전체 페이지를 스크롤하는 번거로움을 줄이고 필요한 정보에 빠르게 접근할 수 있도록 돕습니다.

동적 콘텐츠 표시

특정 조건에 따라 패널을 동적으로 열거나 닫아서 사용자에게 적절한 시점에 필요한 정보를 제공할 수 있습니다. 예를 들어, 사용자가 특정 옵션을 선택했을 때 추가적인 입력 필드가 담긴 패널을 자동으로 열 수 있습니다.

3주요 기능

  • 패널 제어 기능

    • 모든 패널이 열린 상태로 로딩 (WRE, 샘플, YouTube)

    • Enter 키로 패널 열고 닫기 (샘플, YouTube)

    • 패널의 열린 상태를 유지 (WRE, 샘플, YouTube)

  • 패널 상태 확인 기능

    • 특정 패널의 속성 확인 (샘플, YouTube)

    • 모든 열린 패널의 속성 확인 (샘플, YouTube)

  • 이중 Accordion으로 UI 구성 (WRE)

4주요 이벤트

  • onpanelload & onpanelunload (샘플, YouTube)
