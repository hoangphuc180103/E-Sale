CheckBox

1소개

CheckBox 컴포넌트는 HTML의 기본 input 객체가 제공하는 type="checkbox" 와 유사한 인터페이스를 제공함과 동시에, 여러 항목을 한 번에 선택하거나, 데이터 리스트(DataList 또는 LinkedDataList)와의 바인딩을 통해 동적으로 체크 항목을 관리할 수 있도록 도와줍니다. 사용자는 체크 박스를 통해 여러 가지 옵션을 쉽게 선택할 수 있습니다. CheckBox 컴포넌트의 가장 큰 특징은 Radio 컴포넌트와 달리 여러 항목을 동시에 선택할 수 있다는 점입니다. 이러한 특성 덕분에 사용자가 복수의 옵션을 선택해야 하는 다양한 상황에서 유용하게 활용될 수 있습니다.

2주요 용도 및 특징

CheckBox 컴포넌트는 다음과 같은 상황에서 특히 유용하게 사용될 수 있습니다.

다중 선택

사용자가 여러 선택지 중에서 하나 이상을 선택해야 할 때 유용합니다. 예를 들어, 취미, 관심사, 구매할 상품 옵션 등을 선택하는 경우에 활용될 수 있습니다.

동의/확인

특정 약관에 대한 동의 여부나, 작업 수행에 대한 확인을 구할 때 사용될 수 있습니다.

필터링

데이터 목록에서 특정 기준에 따라 항목을 필터링할 때 CheckBox를 사용하여 필터 조건을 선택적으로 적용할 수 있습니다.

설정 옵션

사용자 인터페이스에서 다양한 설정 옵션을 제공하고, 사용자가 원하는 옵션을 선택하거나 해제할 수 있도록 합니다.

작업 목록

완료된 작업이나 선택해야 할 작업 항목을 표시할 때 사용될 수 있습니다.

3주요 기능

  • 선택 항목 설정

    • 직접 입력 (YouTube)

    • DataList와 바인딩 (WRE, 샘플, YouTube)

    • 컴포넌트의 값(value)과 데이터 객체(DataMap, DataList) 연결하기 (WRE)

  • 선택 항목 표시 방법 설정

    • 선택 항목을 표시할 열의 개수 설정 (WRE)

    • 선택 항목을 표시할 행의 개수 설정 (WRE)

  • 선택된 항목의 값 가져오기 (WRE)

  • 전체 항목 선택 및 해제 (WRE)

  • 일부 선택 항목 숨기기 (WRE, 샘플, YouTube)

  • 일부 선택 항목 비활성화하기 (WRE)

    • 정적으로 비활성화하기 (샘플, YouTube)

    • 동적으로 비활성화하기 (샘플, YouTube)

  • 툴팁 설정 (샘플, YouTube)

4주요 이벤트
