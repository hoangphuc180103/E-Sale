TextBox

1소개

TextBox 컴포넌트는 WebSquare AI에서 제공하는 경량화된 출력 전용 컴포넌트입니다. 일반적으로 텍스트 출력을 위한 Output 컴포넌트와 유사한 기능을 제공하지만, 속도 면에서 더 우수하며 가볍게 사용할 수 있다는 장점이 있습니다. HTML의 <div> 태그를 기반으로 구현되며, 일부 HTML 태그( <h1> , <li> , <address> 등)를 지원하는 tagname 속성을 통해 다양한 텍스트 형식을 구현할 수 있습니다.

TextBox 컴포넌트는 단순한 텍스트 표시에 특화되어 있어 페이지 로딩 시간을 단축시키고, 정적 텍스트 콘텐츠를 효율적으로 관리할 수 있도록 도와줍니다. 이는 대량의 텍스트 라벨이나 설명문이 필요한 대시보드, 정보 패널, 상세 페이지 등에서 특히 유용합니다.

Output 컴포넌트처럼 복잡한 포맷팅이나 검증이 필요하지 않고, 단순히 텍스트를 표시하는 것이 주요 목적일 때 TextBox를 사용하면 페이지 성능을 향상시킬 수 있습니다.

2주요 용도 및 특징

TextBox 컴포넌트는 다음과 같은 상황에서 효과적으로 활용될 수 있습니다:

정적 텍스트 표시

라벨, 제목, 설명 텍스트 등 단순한 텍스트 콘텐츠를 빠르게 출력할 수 있습니다.

가벼운 UI 구성 요소

대량의 텍스트 표시가 필요한 대시보드나 정보 패널에서 복잡한 스타일링이나 유효성 검사 없이 간단한 텍스트만 표시할 때 유용합니다.

HTML 태그 활용

다양한 HTML 태그( <h1> , <code> , <address> 등)를 활용하여 제목, 설명, 주소 등의 구문 강조 표현을 할 수 있습니다.

빠른 렌더링 속도

페이지 로딩 시간을 최적화할 수 잇습니다.

경량화 구조

경량한 구조를 유지하면서도 가독성 있는 UI를 구성하고자 할 때 유용합니다.

3주요 기능

  • 데이터 타입 설정 (WRE)

  • 컴포넌트의 값( value )과 데이터 객체(DataMap, DataList) 연결 (WRE)

  • HTML 태그 지원 (샘플, YouTube)

  • 항상 툴팁 표시 (샘플, YouTube)
