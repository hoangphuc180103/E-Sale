TreeView

1소개

TreeView 컴포넌트는 계층적인 데이터를 트리 구조로 시각화하여 사용자에게 직관적인 정보 탐색 환경을 제공합니다. 파일 시스템의 폴더 구조, 조직도, 메뉴 시스템과 같이 부모-자식 관계를 가진 데이터를 직관적으로 표현할 수 있습니다. 드래그 앤 드롭을 통한 동적 편집, 일반 데이터를 계층적인 형태로 변환하는 기능 등을 제공하여 사용자가 복잡한 데이터 구조를 손쉽게 관리할 수 있는 기능을 제공합니다.

2주요 용도 및 특징

TreeView 컴포넌트는 다음과 같은 상황에서 유용하게 활용될 수 있습니다:

조직 구조 시각화

기업의 조직도나 부서별 계층을 명확하게 보여주어 사용자(관리자, 직원)가 조직 내 관계를 한눈에 파악할 수 있도록 돕습니다.

파일 및 폴더 관리

파일 탐색기와 같이 계층적인 파일 및 폴더 구조를 표시하여 사용자가 쉽게 파일을 찾고 관리할 수 있는 인터페이스를 제공합니다.

내비게이션 메뉴 구성

웹 애플리케이션이나 시스템의 복잡한 메뉴 구조를 트리 형태로 구성하여 사용자가 원하는 기능이나 정보에 빠르게 접근할 수 있도록 직관적인 내비게이션을 제공합니다.

카테고리 및 분류 체계

제품 카테고리, 도서 분류 등 계층적인 분류 체계를 시각적으로 표현하여 사용자가 특정 그룹의 항목을 쉽게 탐색하고 선택할 수 있도록 지원합니다.s

3주요 기능

  • 노드 선택/해제

    • 노드의 index 또는 value 로 노드 선택 (WRE)

    • 노드를 선택하면 상위 노드에 선택된 효과 적용 (WRE)

    • 모든 노드의 선택 해제 (WRE)

    • 초기 로딩 시 지정 depth까지 노드 자동 확장하기 (WRE)

  • 툴팁

    • 노드 툴팁에 "w2group" Class를 추가하지 않기 (WRE)

    • 툴팁 변경하기 (WRE)

  • 노드 스타일

    • 특정 노드에 스타일 적용 (샘플, YouTube)

    • 노드 접기/펼치기

      • 특정 노드 접기/펼치기 (샘플, YouTube)

      • 전체 노드 접기/펼치기 (샘플, YouTube)

  • 체크 박스

    • 각 노드에 체크 박스 표시 (샘플, YouTube)

    • 부모 노드 체크 박스를 선택하여 자식 노드 전체를 선택 (WRE, 샘플, YouTube)

  • 노드 라벨 포맷 – customFormatter (WRE)
