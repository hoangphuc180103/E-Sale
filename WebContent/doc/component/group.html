Group

1소개

Group 컴포넌트는 여러 개의 UI 컴포넌트를 논리적으로 그룹핑하여 하나의 단위로 관리할 수 있게 해주는 컨테이너 컴포넌트입니다. 이 컴포넌트를 사용하면 그룹 내의 모든 컴포넌트에 대해 일괄적으로 상태를 제어하거나 스타일을 적용하는 등 효율적인 개발을 가능하게 합니다. 특히 여러 요소를 한 번에 관리해야 하는 경우 매우 유용하게 활용될 수 있습니다. 즉, 개별 컴포넌트들을 일일이 제어하는 대신, 그룹 단위로 일괄 처리가 가능하여 개발 효율성을 크게 향상시킬 수 있습니다.

2주요 용도 및 특징

Group 컴포넌트는 다양한 시나리오에서 활용할 수 있으며, 주요 용도는 다음과 같습니다.

컴포넌트의 일괄 관리

여러 개의 입력 필드나 버튼 등을 하나의 그룹으로 묶어 한 번에 활성화하거나 비활성화할 필요가 있을 때 사용합니다. 예를 들어, 특정 조건이 충족될 때만 입력 필드들을 활성화해야 하는 경우 Group 컴포넌트를 통해 손쉽게 구현할 수 있습니다.

시각적인 그룹화 및 스타일링

관련된 컴포넌트들을 시각적으로 그룹화하여 사용자 인터페이스의 가독성을 높이고, 그룹 전체에 통일된 스타일을 적용하여 디자인의 일관성을 유지할 수 있습니다.

전체 레이아웃 구성

페이지의 헤더, 사이드바, 콘텐츠 영역 등을 각각 그룹으로 묶어 전체적인 레이아웃 구조를 명확하게 정의할 수 있습니다. 이를 통해 반응형 디자인 구현이나 레이아웃 변경 시 보다 효율적인 관리가 가능합니다.

복잡한 계층 구조 구현

중첩된 그룹을 통해 다층적인 컴포넌트 구조를 구성할 수 있습니다. 예를 들어, 폼 내의 섹션별 입력 필드들을 그룹화하거나, 탭 패널 내의 각 탭 콘텐츠를 별도의 그룹으로 관리하는 등의 활용이 가능합니다.

3주요 기능

  • 컴포넌트 관리

    • 일괄 초기화 – init()

    • 일괄 함수 호출

  • 내부 컴포넌트 비활성화

    • 전체 컴포넌트 활성화/비활성화 (샘플, YouTube)

    • 원래 상태는 유지하면서 전체 컴포넌트 활성화/비활성화 (WRE, 샘플, YouTube)

  • 스타일링

    • 일괄 스타일 적용 (샘플, YouTube)

4주요 이벤트

  • onmouseenter (WRE, 샘플, YouTube)

  • onmouseleave (WRE)
