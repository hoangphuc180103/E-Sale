유틸리티

1소개

WebSquare AI는 효율적인 UI 개발을 지원하기 위해 개발자가 자주 사용하는 기능들을 간편하게 사용할 수 있도록 유틸리티 객체 및 함수를 축약하여 제공합니다. 유틸리티 객체를 사용하면 간결한 코드 작성 및 반복 작업 제거로 생산성과 유지보수성이 크게 향상할 수 있습니다.

2주요 기능

  • 화면 관리 기능

    • 화면 재로딩 및 브라우저 새로 고침 (샘플, YouTube)

    • 브라우저의 LocalStorage에 값을 저장, 삭제, 반환 (WRE)

  • 날짜 및 시간 처리

    • 양력/음력 날짜 변환 (샘플, YouTube)

      • 양력으로 변환 (WRE)

      • 음력으로 변환 (WRE)

    • 날짜 유효성 검증 (샘플, YouTube)

    • Date 객체의 포맷을 지정해 문자열로 반환 (WRE)

    • yyyyMMdd 형식의 날짜 문자열에 일 수를 더하거나 빼기 (WRE)

    • yyyyMMdd 형식의 날짜 문자열을 요일 문자열로 반환 (WRE)

  • 기타

    • 디버깅 메뉴 제어 (샘플)

    • JSON 관련 기본 API (WRE)

    • jQuery 문법을 사용하여 컴포넌트의 메소드를 체이닝 기법으로 호출 (WRE)

    • 로그 출력 (WRE)

    • Blob 데이터를 image로 표현 (WRE)
