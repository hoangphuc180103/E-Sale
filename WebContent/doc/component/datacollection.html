DataCollection

1소개

WebSquare AI의 DataCollection은 현재 화면에서 사용되는 데이터를 직관적으로 개체화한 모듈입니다. DataCollection은 단일 데이터(키/값 방식)부터 다중 데이터(리스트 형태)에 이르기까지 폭넓은 데이터를 손쉽게 관리할 수 있도록 설계되어 JSON, XML, JSON Array 형식으로 추가/바꿈/삭제 할 수 있습니다.

2주요 용도 및 특징

DataCollection은 다음과 같은 용도로 사용할 수 있습니다.

UI 컴포넌트와 데이터 관리

DataMap(단일 데이터 객체), DataList(다중 데이터 객체), 그리고 LinkedDataList(필터링/정렬된 결과 객체) 등을 활용하여 화면에 출력할 데이터를 정의합니다.

UI 컴포넌트와 연동하여 데이터를 효율적으로 표시하고 조작합니다.

서버로부터 수신한 단일형(DataMap) 또는 목록형(DataList) 데이터를 웹 브라우저에 출력하는 데 사용됩니다.
