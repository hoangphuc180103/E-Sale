1소개

WebSquare AI의 DataCollection은 현재 화면에서 사용되는 데이터를 직관적으로 개체화하여 UI 컨포넌트와 연계하고, Submission은 서버와의 AJAX 기반 통신을 통해 화면 전환 없이 데이터만 전송하고 수신할 수 있는 모듈로 개발자가 용도에 맞게 유연하게 사용할 수 있습니다.

DataCollection은 단일 데이터(키/값 방식)부터 다중 데이터(리스트 형태)에 이르기까지 폭넓은 데이터를 손쉽게 관리할 수 있도록 설계되어 JSON, XML, JSON Array 형식으로 추가/바꿈/삭제 할 수 있고, 다수의 컨포넌트와 다수의 클래스 화면에서 공유 할 수 있습니다. 또한, 각 데이터 객체는 고유의 ID가 필수적으로 부여되어, 여러 페이지 컴포넌트 간의 데이터 공유 및 복사가 용이합니다.

2주요 용도 및 특징

Submission은 다음과 같은 용도로 사용할 수 있습니다.

서버와의 원활한 데이터 통신

웹 브라우저에서 원격 서버에 존재하는 데이터를 추가, 삭제, 편집 등 관리할 수 있는 인터페이스를 제공합니다.

서버로 전달할 데이터 규격을 정의(Reference)하거나, 서버로부터 받을 데이터 규격을 정의(Target)하는 데 사용됩니다.

웹 페이지 전환 없이 데이터만을 주고받아 효율적인 통신이 가능합니다.

3주요 기능

  • Submission 생성

    • 생성 및 실행 1 (샘플)

    • 생성 및 실행 2 (샘플)

    • Submission 헤더 설정 (샘플)

    • ref 와 target 속성 값에 따른 DataCollection 적용 (WRE)

    • 동적으로 생성, 삭제, 실행 (WRE)

  • 전체 Submission 객체 반환 (샘플)
