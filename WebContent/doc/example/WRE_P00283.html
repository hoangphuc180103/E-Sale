[DataList] 컬럼 데이터에 정렬 적용하기 - 스크립트

1개요

DataList의 'sort' 메소드와 'multisort' 메소드를 사용하여 데이터를 정렬하고, 'clearSort' 메소드를 사용하여 데이터 정렬을 해제한 예제입니다.
이 예제는 DataList의 메소드가 세 가지 사용되었으며, 다음과 같습니다.

  • 단건 컬럼 정렬 : sort

  • 다건 컬럼 정렬 : multisort

  • 정렬 취소 : clearSort

숫자형 정렬을 적용하려면, DataList의 컬럼 속성 'dataType'의 설정 값을 'number' 또는 'bigDecimal'로 지정해야 합니다.

  • 스크립트로 정렬 취소하기

  • 숫자형 데이터로 정렬하기

4구현 예시

4.1스크립트로 단건 컬럼 정렬하기

DataList의'sort' 메소드를 사용하여 스크립트를 작성합니다.
세부 설정은 아래의 스크립트 예시에 작성되어 있습니다.

Example 1.Script

//예제 파일에서는 스크립트 scwin.btn_exam1_1_onclick에 작성되어 있습니다.

// DataList 'dlt_exam_1'의 'Category' 컬럼을 오름차순으로 정렬합니다.
dlt_exam_1.sort("category", 0);
// 첫 번째 인자 : DataList의 컬럼 ID 또는 Index
// 두 번째 인자 : 정렬 옵션 [0,1,2] 0:오름차순, 1:내림차순, 2:정렬 취소

4.2스크립트로 다건 컬럼 정렬하기

DataList의 'multisort' 메소드를 사용하여 스크립트를 작성합니다.
세부 설정은 아래의 스크립트 예시에 작성되어 있습니다.

Example 2.Script

//예제 파일에서는 스크립트 scwin.btn_exam2_1_onclick에 작성되어 있습니다.

// DataList 'dlt_exam_2'의 'Category' 컬럼을 오름차순으로, 'Product' 컬럼을 내림차순으로 정렬합니다.
var options = {};
options.sortIndex = "category product"; // DataList의 컬럼 ID 또는 Index. 공백으로 컬럼을 구분합니다.
options.sortOrder = "1 -1"; // 정렬 기준으로 공백으로 구분합니다. 1:오름차순, -1:내림차순

dlt_exam_2.multisort(options);

4.3스크립트로 정렬 취소하기

DataList의 'clearSort' 메소드를 사용하여 스크립트를 작성합니다.
세부 설정은 아래의 스크립트 예시에 작성되어 있습니다.

Example 3.Script

//예제 파일에서는 스크립트 scwin.btn_sortInit_1_onclick에 작성되어 있습니다.

// DataList 'dlt_exam_1'의 정렬을 해제합니다.
dlt_exam_1.clearSort();

4.4DataList의 'sort' 메소드와 'multisort' 메소드를 호출할 때 숫자형 정렬 설정하기

숫자형 정렬을 적용하려면, DataList의 컬럼 속성 'dataType'의 설정 값을 'number' 또는 'bigDecimal'로 지정해야 합니다.


스크립트로 컬럼의 데이터 유형을 변경하는 기능은 지원하지 않으며 DataList 구성 시 지정해야 합니다.

STEP 1: DataList의 컬럼 속성을 정의합니다.

  • [필수] dataType="number" 또는 "bigDecimal" 또는 "float"
