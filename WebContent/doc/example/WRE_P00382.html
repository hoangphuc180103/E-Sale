[Selectbox] 컴포넌트의 값(value)과 데이터 객체(DataMap, DataList) 연결하기

1개요

Selectbox의 'ref' 속성과 'setRef' 메소드를 사용하여 컴포넌트의 값과 데이터 객체(DataMap, DataList)를 연결하는 예제입니다.
'ref' 속성은 컴포넌트의 값(value)과 데이터 객체의 키 또는 컬럼의 값(value)을 연결하는 기능을 제공합니다. 데이터 객체와 연결되면 값이 동기화됩니다.
'setRef' 메소드는 'ref' 속성의 값을 변경하는 기능을 제공합니다.
'ref'의 설정 값이 리스트형(다건) 데이터 객체의 컬럼일 경우, 데이터 객체의 선택된 행의 컬럼 값과 연결됩니다.
대표적으로 'DataList', 'AliasDataList'가 리스트형 데이터 객체에 해당합니다.
리스트 형식의 데이터 객체에서 행을 선택하는 기능은 데이터 객체의 'initRowPosition' 속성과 'setRowPosition' 메소드를 통해 제공됩니다.

P00382

2구현된 기능

  • DataMap의 'key'와 연결

  • DataList의 'column'과 연결

3예제 테스트 방법

3.1DataMap의 'key'와 연결

'ref' 속성과 데이터 객체가 연결되었을 때, 컴포넌트와 데이터 객체이 동기화되는 것을 확인하고 스크립트로 'ref' 속성이 변경되는 것을 확인합니다.
영역에 구성된 버튼을 순서에 맞게 클릭하여 Selectbox의 선택 값 표시 영역에 출력된 값과 DataMap의 데이터를 확인합니다.
DataMap의 데이터는 '로그 확인'의 Textarea와 브라우저 개발자 도구의 콘솔에 출력됩니다.

4구현 예시

4.1속성으로 데이터 객체와 연결 설정하기

1

Selectbox의 속성을 정의합니다.

  • [필수] ref="data:[데이터 객체 id].[key 또는 column의 id]"

    (주의 사항)

    설정 값의 'data:'은 고정 값입니다.

    (예시)

    예시 1) DataMap 'dma_exam1'의 'key_1' 키와 연결

    ref="data:dma_exam1.key_1"

    예시 2) DataList 'dlt_exam1'의 키 'col_1'과 연결

    ref="data:dlt_exam1.col_1"

Image 11.웹스퀘어 스튜디오의 Component View - 속성 설정 예시

Example 9.Source

<!-- Selectbox 의 소스 본문 예시 -->
<xf:select1 ref="data:dma_exam1.key_1">
  <!-- 중략 -->
</xf:select1>

4.2스크립트로 데이터 객체와 연결 설정하기

1

스크립트를 작성합니다.

Selectbox의 'setRef' 메소드를 사용하여 스크립트를 작성합니다.
세부 설정은 아래의 스크립트 예시에 작성되어 있습니다.

Example 10.Script

//예제 파일에서는 스크립트 'scwin.btn_exam1_3_onclick'에 작성되어 있습니다.

// Selectbox 'sbx_exam1'의 'ref' 속성의 설정 값을 DataMap 'dma_exam1'의 'key_2' 키로 변경합니다.
// 설정 값의 'data:'는 고정 값입니다.
sbx_exam1.setRef("data:dma_exam1.key_2");
