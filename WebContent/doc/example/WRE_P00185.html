[GridView] 셀의 배경색 설정하기

1개요

GridView의 'setCellBackgroundColor' 메소드를 사용하여, 특정 셀의 배경색을 설정한 예제입니다.

P00185

2구현된 기능

  • 셀의 배경색 설정하기

4구현 예시

4.1셀의 배경색 설정하기

1

스크립트를 작성합니다.

GridView의 메소드 'setCellBackgroundColor'를 사용합니다.

Example 1.Script

//예제 파일의 스크립트 "scwin.btn_ex1_onclick" 또는 "scwin.btn_ex2_onclick"를 참고하세요.

//GridView 'grd_exam1'의 'B' 컬럼의 2번째 행의 배경색을 'peru'로 설정하기
grd_exam1.setCellBackgroundColor(1, "col_b", "peru");

//GridView 'grd_exam1'의 'A' 컬럼의 1번째 행의 배경색을 '#9ACD32'로 설정하기
grd_exam1.setCellBackgroundColor(0, "col_a", "#9ACD32");

5주요 API

  • setCellBackgroundColor( rowIndex , colIndex , color )
