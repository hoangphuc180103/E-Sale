[Calendar] 지정된 휴일 제거하기

1개요

Calendar의 'removeHoliday' 메소드를 사용하여 설정된 휴일을 제거하는 예제입니다.

P00075

2구현된 기능

  • 컴포넌트에 휴일이 지정된 상태

  • 컴포넌트에 지정된 휴일 제거하기

3예제 테스트 방법

화면 로딩 시 Calendar에 2024년 12월 1일이 선택되도록 설정되었습니다.

1

STEP 1: Calendar의 휴일을 확인합니다.

휴일이 매년 12월 12일, 12월 30일, 12월 31일로 지정된 상태입니다.

Image 1.브라우저(Chrome) 실행 예시 - 휴일이 지정된 상태

2

STEP 2: 지정된 휴일이 제거하기

버튼 '휴일 설정 제거하기'를 클릭합니다. Calendar에 휴일 표시가 제거된 것을 확인합니다.

Image 2.브라우저(Chrome) 실행 예시 - 휴일에서 제거된 상태

4구현 예시

휴일 지정에 대한 내용은 제외되었습니다. 휴일 지정에 대한 내용은 아래의 예제에 포함되어있습니다.

메뉴에서 검색어 '휴일'을 통해 확인할 수 있습니다.


- 예제명 : [Calendar] 특정 날짜를 휴일로 지정하기 (검색 키워드 : P00073)

- 예제명 : [Calendar] 특정 날짜를 휴일로 지정하기 - DataList 연결 (검색 키워드 : P00074)

4.1지정된 휴일이 제거하기

Example 1.Script

//컴포넌트 cal_exam1의 지정된 휴일을 제거합니다.
cal_exam1.removeHoliday();
