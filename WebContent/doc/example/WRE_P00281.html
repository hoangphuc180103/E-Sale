[DataList] 지정한 컬럼의 데이터와 주어진 값이 일치하는 행 데이터 반환받기

1개요

DataList의 메소드를 사용하여 지정한 컬럼의 데이터와 주어진 문자열이 일치하는 행의 데이터를 반환받는 예제입니다.
반환 데이터의 유형에 따라 메소드가 분리되어 있습니다. 메소드의 인자는 동일합니다.
이 예제에서 사용한 반환 데이터의 타입에 따른 메소드는 다음과 같습니다.

  • JSON 형식 : getMatchedJSON

  • 1차원 Array 형식 + 컬럼 정보 : getMatchedArray

  • 2차원 Array 형식 : getMatchedData

  • XML 형식 : getMatchedXML

  • Row Index가 담긴 1차원 Array 형식 : getMatchedIndex

각 메소드의 부가 기능으로는 데이터 검색 조건(일치 또는 포함) 설정과 검색할 행의 범위 설정이 있습니다.

2구현된 기능

  • 메소드별 반환 데이터 형식 비교하기

  • 데이터 일치 여부 설정 비교하기

  • 검색할 행의 범위 설정 비교하기

4구현 예시

4.1검색 데이터를 'JSON' 형식으로 반환받기

DataList의 'getMatchedJSON' 메소드를 사용하여 스크립트를 작성합니다.
세부 설정은 아래의 스크립트 예시에 작성되어 있습니다.

Example 13.Script

//예제 파일에서는 스크립트 scwin.btn_exam1_1_onclick에 작성되어 있습니다.

// DataList 'dlt_exam'의 'Category' 컬럼의 값이 'Networking'과 일치하는 데이터를 JSON으로 반환받습니다.
let result = dlt_exam.getMatchedJSON("category", "Networking");
반환 데이터는 JSON 형식입니다.
반환된 JSON의 키 'rowStatus'는 웹스퀘어 엔진에서 생성한 키입니다. 행(Row)의 데이터 상태를 확인할 수 있습니다.

Example 14.Result

[
    {"category":"Networking","product":"SpeedLink","rowStatus":"R"},
    {"category":"Networking","product":"LinkSecure","rowStatus":"R"}
]

4.2검색 데이터를 '1차원 Array + 컬럼 정보' 형식으로 반환받기

DataList의 'getMatchedArray' 메소드를 사용하여 스크립트를 작성합니다.
세부 설정은 아래의 스크립트 예시에 작성되어 있습니다.

Example 15.Script

//예제 파일에서는 스크립트 scwin.btn_exam1_2_onclick에 작성되어 있습니다.

// DataList 'dlt_exam'의 'Category' 컬럼의 값이 'Networking'과 일치하는 데이터를 '1차원 Array 형식 + 컬럼 정보'으로 반환받습니다.
let result = dlt_exam.getMatchedArray("category", "Networking")
반환되는 데이터는 JSON 형식으로, KEY 'data'에는 DataList의 전체 데이터가 1차원 배열로, KEY 'columnInfo'에는 컬럼의 ID가 1차원 배열로 구성되어 있습니다.

Example 16.Result

{
    "columnInfo":["category","product"],
    "data":["Networking","SpeedLink","Networking","LinkSecure"]
}

4.6데이터 일치 여부 설정 비교하기

아래의 DataList의 메소드를 사용하여 스크립트를 작성합니다.

  • getMatchedJSON : JSON 형식

  • getMatchedArray : 1차원 Array 형식 + 컬럼 정보

  • getMatchedData : 2차원 Array 형식

  • getMatchedXML : XML 형식

  • getMatchedIndex : Row Index가 담긴 1차원 Array 형식

각 메소드는 반환 데이터의 유형만 다르며 인자 값의 구성을 동일합니다.
이 예시는 'getMatchedJSON' 메소드를 사용하여 작성한 스크립트입니다.
세부 설정은 아래의 스크립트 예시에 작성되어 있습니다.

Example 23.Script

//예제 파일에서는 스크립트 'scwin.btn_exam2_1_onclick'과 'scwin.btn_exam2_2_onclick'에 작성되어 있습니다.

// 예시 1) DataList 'dlt_exam'의 'Category' 컬럼의 값이 'Services'와 일치하는 데이터를 JSON으로 반환받습니다. - 3번째 인자값을 true로 지정
let result1 = dlt_exam.getMatchedJSON("category", "Services", true);

// 예시 2) DataList 'dlt_exam'의 'Category' 컬럼의 값에 'Services'가 포함된 데이터를 JSON으로 반환받습니다. - 3번째 인자값을 false로 지정
let result2 = dlt_exam.getMatchedJSON("category", "Services", false);

  • getMatchedXML : XML 형식

  • getMatchedIndex : Row Index가 담긴 1차원 Array 형식

각 메소드는 반환 데이터의 유형만 다르며 인자 값의 구성을 동일합니다.
이 예시는 'getMatchedJSON' 메소드를 사용하여 작성한 스크립트입니다.
세부 설정은 아래의 스크립트 예시에 작성되어 있습니다.

Example 24.Script

//예제 파일에서는 스크립트 'scwin.btn_exam3_1_onclick'과 'scwin.btn_exam3_2_onclick'에 작성되어 있습니다.

// 예시 1) DataList 'dlt_exam'의 전체 행을 대상으로 'Category' 컬럼의 값이 'Cloud Services'와 일치하는 데이터를 JSON으로 반환받습니다.
let result1 = dlt_exam.getMatchedJSON("category", "Cloud Services", true);

// 예시 2) DataList 'dlt_exam'의 0~2번째 행을 대상으로 'Category' 컬럼의 값이 'Cloud Services'와 일치하는 데이터를 JSON으로 반환받습니다. - 4번째 인자와 5번째 인자를 지정.
let result2 = dlt_exam.getMatchedJSON("category", "Cloud Services", true, 0, 2);
