[GridView] 셀 포맷 초기화하기

1개요

GridView의 셀에 적용된 포맷을 메소드를 사용하여 초기화하는 예제입니다.

다음은 예제에서 사용한 메소드와 설명입니다.

  • setDisplayFormat(colIndex, displayFormat) : 그리드의 컬럼에 포맷을 설정합니다.

  • setDisplayFormatter(colIndex, displayFormatter) : 그리드의 컬럼에 formatter 함수를 설정합니다.

  • setCustomFormatter(columnInfo, customFormatter) : 그리드 컬럼의 customFormatter 속성 값을 설정합니다.

4.1displayFormatter 설정하기

'날짜1', '날짜2' 컬럼에 displayFormatter 함수를 적용합니다.

Image 3.웹스퀘어 스튜디오의 Component View - '날짜1' 속성 설정 예시

Example 1.Script

scwin.dateFormat_A2Format = function(data) {
    var dd = data.substr(6,2);
    var MM = data.substr(4,2);
    var yy = data.substr(2,2);
    var result = dd + "-" + MM + "-" + yy;
    return result;
}

scwin.dateFormat2_A2Format = function(data) {
    var dd = data.substr(6,2);

    var ssn = data.replace("-", "");

4.4전체 포맷 초기화하기

전체 포맷 초기화 버튼에 'onclick' 이벤트 핸들러를 정의합니다.
예제 파일에서는 핸들러로 사용할 메소드명을 다음과 같이 정의하였습니다.

Image 7.웹스퀘어 스튜디오의 Component View - 이벤트 설정 예시

스크립트 탭에서 핸들러를 정의합니다.

Example 4.Script

scwin.btn_reset_onclick = function (e) {
    for(var idx = 0; idx < grd_Main.getColumnOrder().length; idx++){
        grd_Main.setDisplayFormat( idx, "" );
        grd_Main.setCustomFormatter(idx, "");
        grd_Main.setDisplayFormatter( idx, "" );
    }
};
