[InputCalendar] 클릭할 경우 현재 날짜를 선택해주는 Today 버튼을 숨기거나 표시하기

1개요

InputCalendar의 'showToday' 속성을 사용하여 달력에 Today 버튼을 표시 여부를 설정한 예제입니다.
달력의 하단에 Today 버튼이 함께 표시되는 것이 기본 설정입니다. Today 버튼을 클릭하면 현재 날짜를 선택할 수 있습니다.

P00220

2구현된 기능

  • 'showToday' 속성을 사용하여 Today 버튼을 표시하기

  • 'showToday' 속성을 사용하여 Today 버튼을 표시하지 않기

3예제 테스트 방법

3.1'showToday' 속성을 사용하여 Today 버튼을 표시하기

예제 영역 '(기본 설정) showToday = "true"'에서 테스트합니다.

1

STEP 1: 달력 아이콘을 클릭합니다.

Image 1.브라우저(Chrome) 실행 예시 - 캘린더 아이콘

2

STEP 2: 실행 결과를 확인합니다.

캘린더 하단 영역에 '오늘'(Today) 버튼이 표시됩니다.

Image 2.브라우저(Chrome) 실행 예시

3.2'showToday' 속성을 사용하여 Today 버튼을 표시하지 않기

예제 영역 'showToday = "false"'에서 테스트합니다.

1

STEP 1: 달력 아이콘을 클릭합니다.

Image 3.브라우저(Chrome) 실행 예시 - 캘린더 아이콘

2

STEP 2: 실행 결과를 확인합니다.

'오늘'(Today) 버튼이 표시되지 않습니다.

Image 4.브라우저(Chrome) 실행 예시

4구현 예시

4.1Today 버튼을 표시하지 않기

1

InputCalendar의 속성을 정의합니다.

  • [필수] showToday="false"

    [default: true, false] 설정 값을 "true"로 설정하면 달력에 Today버튼이 표시됩니다. "false"로 설정하면 버튼이 표시되지 않습니다.

Image 5.웹스퀘어 스튜디오의 Component View - 속성 설정 예시

Example 1.Source

<!-- inputCalendar 의 소스 본문 예시 -->
<w2:inputCalendar showToday="false" id="ica_exam_2">
</w2:inputCalendar>
