[GridView] 열 고정 시 숨겨진 열을 포함하여 계산할지 설정하기

1개요

GridView의 'fixedColumnWithHidden' 속성을 사용하여 열 고정 기능을 적용할 때, 숨겨진 열을 포함하여 계산할지 여부를 설정한 예제입니다.

이 예제에서 열 고정 기능은 'fixedColumn' 속성을 사용하여 설정되었습니다.

P00345

2구현된 기능

  • 열 고정 시 숨김 열을 포함해서 계산

  • 열 고정 시 숨김 열을 제외하고 계산

3예제 테스트 방법

3.1열 고정 시 숨김 열을 포함해서 계산

예제 영역 '(기본 값) 2번째 열 고정하기 - 숨김 열을 포함'에 구성된 GridView에서 테스트합니다.

1

실행된 결과를 확인합니다.

GridView의 첫 번째 열이 숨겨진 상태입니다.
열 고정이 'B'까지 적용되어 있습니다.

Image 1.브라우저(Chrome) 실행 예시

3.2열 고정 시 숨김 열을 제외하고 계산

예제 영역 '2번째 열 고정하기 - 숨김 열을 미포함'에 구성된 GridView에서 테스트합니다.

1

실행된 결과를 확인합니다.

GridView의 첫 번째 열이 숨겨진 상태입니다.
열 고정이 'C'까지 적용되어 있습니다.

Image 2.브라우저(Chrome) 실행 예시

4구현 예시

4.1열 고정 계산 시 숨김 열의 포함 여부 지정하기

1

GridView의 속성을 정의합니다.

  • [필수] fixedColumnWithHidden="옵션 값"

    [default: true, false] 열 고정 계산 시 숨김 열의 포함 여부를 설정합니다.

    (옵션 설명)

    - true : 숨김 열을 포함하여 계산

    - false : 숨김 열을 제외하고 계산

  • [필수] fixedColumn="열의 위치" 또는 fixedRightColumn="열의 위치"

    고정할 열의 위치로 열의 순서는 1부터 시작합니다.

Image 3.웹스퀘어 스튜디오의 Component View - 속성 설정 예시

Example 1.Source

<w2:gridView fixedColumnWithHidden="true" fixedColumn="2">
    <!-- 중략 -->
</w2:gridView>
