4구현 예시

4.1PageControl의 총 페이지수를 설정하기

PageControl의 'setCount' 메소드를 사용하여 스크립트를 작성합니다.

세부 설정은 아래의 스크립트 예시에 작성되어 있습니다.

Example 1.Script

//예제 파일에서는 스크립트 scwin.btn_exam1_1_onclick, scwin.btn_exam1_2_onclick에 작성되어 있습니다.

// PageControl 'pgc_exam'의 총 페이지 수를 8로 설정합니다.
pgc_exam.setCount(8);
