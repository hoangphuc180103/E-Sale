[Input] 소수점 입력 길이 제한하기 - maxlength

1개요

Input의 'dataType'을 'float'으로 적용하고 'maxlength' 속성을 사용하여, 소수점 입력 길이 제한을 적용한 예제입니다.

P00441

2구현된 기능

  • 소수점 값 입력하기 - dataType : float

  • 소수점 입력 길이 제한 - maxlength : 4.2

  • 입력 값 유효성 검사 - validateOnInput : true

4구현 예시

1

Input의 속성을 정의합니다.

  • [필수] dataType="float"

    [default:text, number, float, date, time, bigDecimal,euro,rupee,tenge] value의 dataType을 지정합니다.

  • [필수] maxlength="4.2"

    입력 가능한 최대 길이를 설정합니다.

    소수점 단위로도 지정이 가능합니다.

    정수는 4자리 수 까지, 소수점은 2자리 수 까지 입력할 수 있습니다.

  • [필수] validateOnInput="true"

    [default:false, true] oninput 이벤트 시점에 유효성 검사를 수행합니다.

    dataType이 'float'인 경우 숫자 값만 입력 허용됩니다.

Image 7.웹스퀘어 스튜디오의 Component View - 속성 설정 예시
