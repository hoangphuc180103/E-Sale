날짜(yyyyMMdd) 형식의 문자열을 양력 날짜로 반환받기

1개요

'WebSquare.date.toSolar' 메소드를 사용하여 날짜(yyyyMMdd) 형식의 문자열을 양력 날짜로 변환하는 예제입니다.

P00403

음력 날짜로 변환하는 경우 메소드 'WebSquare.date.toLunar'로 구현할 수 있습니다.

2구현된 기능

  • 날짜(yyyyMMdd) 형식의 문자열을 양력 날짜로 변환하기

4구현 예시

4.1날짜(yyyyMMdd) 형식의 문자열을 양력 날짜로 변환하기

'WebSquare.date.toSolar' 메소드를 사용하여 스크립트를 작성합니다.
세부 스크립트는 아래의 예시에 작성되어 있습니다.

Example 1.Script

// 예제 파일에서는 스크립트 'scwin.ica_exam_1_toSolar'에 작성되어 있습니다.

// 문자열 '20241231'를 양력 날짜로 반환받습니다.
var result = WebSquare.date.toSolar('20241231');
// 반환 예시) 20250130
