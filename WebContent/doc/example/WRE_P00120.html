[GridView] 목록형 inputType의 정렬할 데이터의 출처 설정하기

1개요

GridView 바디 컬럼의 'inputType'이 목록(콤보)형인 경우 정렬할 데이터의 출처를 설정하는 예제입니다.
정렬 대상의 기본 설정 값은 'value'입니다. 설정을 통해 'label'로 지정할 수 있습니다.

적용 가능한 inputType은 select, autoComplete입니다.

P00120

2구현된 기능

  • (기본 설정) 항목의 value를 대상으로 정렬하기

  • 항목의 label을 대상으로 정렬하기

3예제 테스트 방법

3.1(기본 설정) 항목의 value를 대상으로 정렬하기

1

STEP 1: GridVIew의 목록에 연결된 DataList의 데이터를 확인합니다.

예제 영역 '(참고 정보) 목록 데이터'의 GridView에 출력된 데이터를 확인합니다.

  • 컬럼 "label" : 목록의 label에 연결

  • 컬럼 "code" : 목록의 value에 연결

4구현 예시

4.1항목의 label을 대상으로 정렬하기

1

STEP 1: GridView의 속성을 정의합니다.

  • [필수] sortable="true"

    gridView의 헤더 클릭을 통한 데이터 정렬 지원 여부

  • [선택] showSortableImage="true"

    정렬 가능한 컬럼의 헤더에 정렬 이미지를 출력.

  • [선택] sortEvent="onclick"

    [default: ondblclick, onclick] 정렬을 수행할 이벤트를 정의.

Image 7.웹스퀘어 스튜디오의 Component View - 속성 설정 예시

2

STEP 2: GridView 바디 컬럼의 속성을 정의합니다.

inputType이 select, autoComplete인 경우 적용됩니다.

  • [필수] sortLabel="true"

    label 값을 기준으로 정렬

  • [선택] viewType="icon"

    컬럼의 inputType에 헤당하는 아이콘을 표시

Image 8.웹스퀘어 스튜디오의 Component View - 바디 컬럼 속성 설정 예시

Example 1.Source

<!-- gridView 의 소스 본문 예시 -->
<w2:gridView sortable="true" sortEvent="onclick" showSortableImage="true" dataList="data:dlt_exam_2">
    <!-- 중략 -->
    <w2:gBody id="gBody1">
        <w2:row id="row2">
            <!-- 중략 -->
            <w2:column sortLabel="true" viewType="icon" id="select" inputType="select">
                <w2:choices>
                    <w2:itemset nodeset="data:dlt_exam_code">
                        <w2:label ref="label"></w2:label>
                        <w2:value ref="code"></w2:value>
                    </w2:itemset>
                </w2:choices>
            </w2:column>
            <!-- 중략 -->
        </w2:row>
    </w2:gBody>
</w2:gridView>
