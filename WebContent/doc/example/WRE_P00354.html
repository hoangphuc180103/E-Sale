[Input] 입력 필드에 힌트 문자열 설정하기

1개요

Input의 'placeholder' 속성과 'setPlaceholder' 메소드를 사용하여 입력 필드에 힌트 문자열(placeholder)을 설정한 예제입니다.
'placeholder' 속성은 입력 필드에 사용자에게 입력해야 할 내용이나 형식을 알려주는 힌트 문자열을 출력하는 기능을 제공합니다.
이 힌트는 입력 필드에 아무 내용도 입력하지 않은 경우에 표시되며, 사용자가 입력을 시작하면 문자열은 사라집니다.
'setPlaceholder' 메소드는 'placeholder' 속성의 값을 변경하는 기능을 제공합니다.

4.2메소드로 힌트 문자열 설정하기

Input의 'setPlaceholder' 메소드를 사용하여 스크립트를 작성합니다.
세부 설정은 아래의 스크립트 예시에 작성되어 있습니다.

Example 2.Script

//예제 파일에서는 스크립트 'scwin.btn_exam1_1_onclick'에 작성되어 있습니다.

// Input 'ibx_exam1'의 'placeholder' 속성 설정 값을 변경합니다.
ibx_exam1.setPlaceholder("변경된 입력 힌트 예시입니다.");
