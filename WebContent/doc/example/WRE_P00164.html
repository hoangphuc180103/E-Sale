[컴포넌트 공통] 스크립트로 이벤트 해제(제거)하기

1개요

컴포넌트의 'unbind' 메소드를 사용하여, 컴포넌트에 등록된 이벤트 핸들러를 제거한 예제입니다.

P00164

2구현된 기능

  • 스크립트로 컴포넌트의 모든 이벤트의 모든 핸들러 해제하기

  • 스크립트로 컴포넌트의 특정 이벤트의 모든 핸들러 해제하기

  • 스크립트로 컴포넌트의 특정 이벤트의 특정 핸들러 해제하기

3예제 테스트 방법

3.1[공통] 로그 확인 방법

예제 영역 '로그 확인'의 textarea에 로그를 출력하고 있습니다.

Example 1.Log

[07:21:26][공용] onclick 이벤트 핸들러 - 메소드 scwin.btn_example_test_onclick_user

3.2스크립트로 컴포넌트의 모든 이벤트의 모든 핸들러 해제하기

1

STEP 1: 초기 상태 확인하기

예제 영역 '모든 이벤트의 모든 핸들러 제거하기'의 '테스트 버튼 2' 버튼에는 'onclick' 핸들러 1개, 'onmouseup' 핸들러 1개가 등록되어있습니다.

2

STEP 2: '테스트 버튼 2' 버튼을 클릭합니다.

'onclick' 이벤트와 'onmouseup' 이벤트가 발생합니다.

3

STEP 3: 실행 결과 확인하기

영역 '로그 확인'에 출력된 로그를 확인합니다.

Example 2.Log

[06:19:31] [테스트 버튼 2] - onmouseup 발생 - 메소드 scwin.btn_exam_test2_onmouseup
[06:19:31] [테스트 버튼 2] - onclick 발생 - 메소드 scwin.btn_exam_test2_onclick

출력된 로그를 삭제합니다.

4

STEP 4: '모든 이벤트의 모든 핸들러 제거하기 - unbind' 버튼을 클릭합니다.

'테스트 버튼 2' 버튼의 모든 이벤트 핸들러가 제거됩니다.

5

STEP 5: 실행 결과 확인하기

영역 '로그 확인'에 출력된 로그를 확인합니다.

실행된 스크립트 예시가 출력됩니다.

Example 3.Log

[06:21:09] btn_exam_test2.unbind();

출력된 로그를 삭제합니다.

6

STEP 6: '테스트 버튼 2' 버튼을 클릭합니다.

7

STEP 7: 실행 결과 확인하기

영역 '로그 확인'에 출력된 로그를 확인합니다.

출력된 로그가 없습니다.

4구현 예시

4.1스크립트로 이벤트 해제하기

유형 1: 컴포넌트의 모든 이벤트의 모든 핸들러 해제하기

Example 10.Script

//id가 btn_example_test인 컴포넌트의 예시입니다.

//컴포넌트의 모든 이벤트의 모든 핸들러를 해제
btn_example_test.unbind();

유형 2: 컴포넌트의 특정 이벤트의 모든 핸들러 해제하기

Example 11.Script

//id가 btn_example_test인 컴포넌트의 예시입니다.

//컴포넌트의 onclick 이벤트 핸들러 모두 해제.
btn_example_test.unbind("onclick");

유형 3: 컴포넌트의 특정 이벤트의 특정 핸들러 해제하기

Example 12.Script

//id가 btn_example_test인 컴포넌트의 예시입니다.

//컴포넌트의 onclick 이벤트의 'scwin.btn_example_test_onclick_user' 핸들러 해제
btn_example_test.unbind("onclick", scwin.btn_example_test_onclick_user);
