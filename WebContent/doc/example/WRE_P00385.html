[Span] 데이터 타입 설정에 따른 출력 값 비교하기

1개요

Span의 'dataType' 속성과 'displayFormat' 속성을 사용하여 데이터 타입에 따른 출력 값 형식을 비교하는 예제입니다.
'dataType' 속성은 컴포넌트의 값('label' 속성의 설정 값)을 화면에 표시할 때, 출력 값의 형식을 설정하기 위해 사용합니다.
출력 형식은 'displayFormat' 속성의 설정 값을 참조하여 적용됩니다.
'displayFormat' 속성의 설정 값이 없는 경우, 'dataType' 속성의 설정 값에 따라 기본 출력 형식이 설정된 경우도 있습니다.
다음은 'dataType' 속성의 설정 값에 따른 기능입니다.

  • "text" : 문자열.

  • "number" : 숫자 형식의 문자열.

  • "date" : 날짜 형식의 문자열. 기본 서식은 'yyyy/MM/dd'입니다.

  • "time" : 시간 형식의 문자열. 기본 서식은 'HH:mm'입니다.

P00385

컴포넌트의 값('label' 속성의 설정 값)은 서식이 적용되지 않은 설정 값이 할당됩니다.

서식이 적용된 값은 'getFormatValue' 메소드를 통해 반환받을 수 있습니다.

2구현된 기능

  • 'dataType'의 설정 값이 'text'인 경우의 출력 예시

  • 'dataType'의 설정 값이 'number'인 경우의 출력 예시

  • 'dataType'의 설정 값이 'date'인 경우의 출력 예시

1

STEP 1: 초기 상태를 확인합니다.

예제 영역 '(기본 설정) dataType="text"'의 출력 값을 확인합니다.
별도의 조작은 없으며, 화면에 출력된 'dataType', 'label', 'displayFormat' 속성의 설정 값에 따른 실행 결과를 비교합니다.

STEP 2: 실행 결과를 확인합니다.

Example 1.설정 속성 별 실행 결과

예시 1)
속성: dataType="text" label="ms" displayFormat=""
설명: 기본 서식이 지정되어 있지 않아 값이 그대로 출력됩니다.
실행 결과: ms

예시 2)
속성: dataType="text" label="ms" displayFormat="(단위: ##)"
설명: 'label' 속성의 설정 값의 문자열 길이가 고정일 때 '#'을 사용하여 서식을 지정할 수 있습니다. 컴포넌트 값(문자열)의 길이가 2이기 때문에 '##'으로 설정되었습니다.
실행 결과: (단위: ms)

예시 3)
속성: dataType="text" label="12345000" displayFormat="#,###"
설명: 3자리 마다 ','를 출력하려면 'dataType' 속성의 설정 값을 'number'로 지정해야 합니다.
실행 결과: 12345,000

4.1속성으로 데이터 타입 설정하기

1

속성을 정의합니다.

  • [필수] dataType="옵션 값"

    (옵션 설명)

    - "text" : 문자열.

    - "number" : 숫자 형식의 문자열.

    - "date" : 날짜 형식의 문자열. 기본 서식은 'yyyy/MM/dd'입니다.

    - "time" : 시간 형식의 문자열. 기본 서식은 'HH:mm'입니다.

    (예시)

    예시) dataType="number"

    세부 예시는 이 문서의 '예제 테스트 방법'을 참고합니다.

  • [선택] displayFormat="서식 문자열"

    'dataType' 속성의 설정 값에 따라 적용됩니다. Excel의 서식과 흡사합니다.

    (예시)

    예시) displayFormat="#,###" dataType="number"

    세부 예시는 이 문서의 '예제 테스트 방법'을 참고합니다.
