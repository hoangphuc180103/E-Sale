[InputCalendar] 날짜 값의 포맷을 지정해 문자열로 반환받기

1개요

InputCalendar의 'getFormattedValue' 메소드를 사용하여 날짜 값에 포맷을 설정하여 문자열로 반환받는 예제입니다.

P00451

2구현된 기능

  • 설정한 포맷으로 날짜 값 반환받기

3예제 테스트 방법

3.1날짜 포맷 입력하기

1

STEP 1: 초기 상태를 확인합니다.

InputCalendar에 'yyyy-MM-dd' 형태로 현재 날짜가 설정된 상태입니다.

Image 1.브라우저(Chrome) 실행 예시

2

STEP 2: ''dd-MM yyyy' 형태로 날짜 값 반환받기' 버튼을 클릭합니다.

3

STEP 3: 실행 결과를 확인합니다.

'dd-MM yyyy' 형태로 포맷이 적용되어 문자열로 반환됩니다.

예제 영역 '로그 확인'의 textarea 또는 브라우저 개발자 도구의 콘솔에 출력된 로그를 확인합니다.

Example 1.Log

[14:42:35] dd-MM yyyy : 03-12 2025

4구현 예시

4.1반환 받을 포맷 설정하기

'getFormattedValue' 메소드를 사용하여 스크립트를 작성합니다.

파라미터에 적용할 포맷의 대소문자를 주의하여 입력합니다. 아래는 포맷에 설정할 수 있는 값입니다.
파라미터가 작성되지 않은 경우 inputCalendar의 displayFormat 속성에 적용된 패턴을 사용합니다.

  • y: Year

  • M: Month

  • d: Day

  • H: Hour

  • m: Minute

  • s: Second

  • S: Millisecond

Example 2.Script

// 예제 파일에서는 스크립트 scwin.btn_setFormat_onclick에 작성되어 있습니다.

// 반환받을 포맷 지정
var format = "dd-MM yyyy";

// format 파라메터를 넘기는 경우
var returnValue = ipc_format.getFormattedValue(format);
