[컴포넌트 공통] 스크립트로 이벤트 발생시키기

1개요

컴포넌트의 'trigger' 메소드를 사용하여, 컴포넌트에 등록된 이벤트를 발생시키는 예제입니다.

P00165

2구현된 기능

  • 스크립트로 컴포넌트의 이벤트 발생시키기

  • 스크립트로 컴포넌트의 이벤트를 사용자 인수 값을 정의하여 발생시키기

3예제 테스트 방법

3.1[공통] 로그 확인 방법

예제 영역 '로그 확인'의 textarea에 로그를 출력하고 있습니다.

Example 1.Log

[14:23:55] ** 메소드 scwin.btn_ex5_onclick **
[14:23:55] btn_exam_test5.trigger("onclick");
[14:23:55] [테스트 버튼 5] - onclick 발생 - 메소드 scwin.btn_exam_test5_onclick

3.2스크립트로 컴포넌트의 이벤트 발생시키기

1

STEP 1: 초기 상태 확인하기

예제 영역 '이벤트 발생 시키기 - trigger'의 '테스트 버튼 5' 버튼에는 'onclick' 핸들러 1개가 등록되어있습니다.

2

STEP 2: '테스트 버튼 5' 버튼을 클릭합니다.

'onclick' 이벤트가 발생합니다.

3

STEP 3: 실행 결과 확인하기

영역 '로그 확인'에 출력된 로그를 확인합니다.

Example 2.Log

[06:46:19] [테스트 버튼 5] - onclick 발생 - 메소드 scwin.btn_exam_test5_onclick

출력된 로그를 삭제합니다.

4

STEP 4: '이벤트 발생 - trigger' 버튼을 클릭합니다.

'테스트 버튼 5' 버튼의 'onclick' 이벤트가 발생됩니다.

5

STEP 5: 실행 결과 확인하기

영역 '로그 확인'에 출력된 로그를 확인합니다.

실행된 스크립트 예시와 '테스트 버튼 5' 버튼의 'onclick' 핸들러 로그가 출력됩니다.

Example 3.Log

[06:48:28] ** 메소드 scwin.btn_ex5_onclick **
[06:48:28] btn_exam_test5.trigger("onclick");
[06:48:28] [테스트 버튼 5] - onclick 발생 - 메소드 scwin.btn_exam_test5_onclick

3.3스크립트로 컴포넌트의 이벤트를 사용자 인수 값을 정의하여 발생시키기

1

STEP 1: 초기 상태 확인하기

예제 영역 '이벤트 발생 시키기 - trigger - 사용자 인수 값 정의하기'의 '테스트 버튼 6' 버튼에는 'onclick' 핸들러 1개가 등록되어있습니다.

2

STEP 2: '테스트 버튼 6' 버튼을 클릭합니다.

'onclick' 이벤트가 발생합니다.

3

STEP 3: 실행 결과 확인하기

영역 '로그 확인'에 출력된 로그를 확인합니다.

Example 4.Log

[06:51:23] [공용] onclick 이벤트 핸들러 - 메소드 scwin.btn_example_test_onclick_user
[06:51:23] e.exampleParam : undefined

출력된 로그를 삭제합니다.

4

STEP 4: '이벤트 발생 - trigger - 사용자 인수 값 정'의하기' 버튼을 클릭합니다.

'테스트 버튼 6' 버튼의 'onclick' 이벤트가 발생됩니다.

개발자가 정의한 인수가 핸들러에 전달됩니다.

5

STEP 5: 실행 결과 확인하기

영역 '로그 확인'에 출력된 로그를 확인합니다.

실행된 스크립트 예시와 '테스트 버튼 6' 버튼의 'onclick' 핸들러 로그가 출력됩니다.

Example 5.Log

[06:53:46] ** 메소드 scwin.btn_ex6_onclick **
[06:53:46] btn_exam_test6.trigger("onclick", [{"exampleParam":"C0001"}]);
[06:53:46] [공용] onclick 이벤트 핸들러 - 메소드 scwin.btn_example_test_onclick_user
[06:53:46] e.exampleParam : C0001

4구현 예시

4.1스크립트로 이벤트 발생시키기

유형 1: 컴포넌트의 이벤트 발생시키기

Example 6.Script

//id가 btn_example_test인 컴포넌트의 예시입니다.

//컴포넌트의 click 이벤트를 발생시킨다.
btn_example_test.trigger("onclick");

유형 2: 컴포넌트의 이벤트 발생 시 사용자가 정의한 값 넘기기

Example 7.Script

//id가 btn_example_test인 컴포넌트의 예시입니다.

//컴포넌트의 onclick 이벤트를 발생시키며 사용자 인수 값을 정의한다.
btn_example_test.trigger("onclick", [{"exampleParam" : "C0001"}]);

Example 8.Script

//이벤트 핸들러 작성 예시
scwin.btn_example_test_onclick_user = function (e) {
    var userParam = e.exampleParam;
};

5주요 API
