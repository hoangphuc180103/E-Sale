컴포넌트의 자식 또는 자손 컴포넌트 반환받기

1개요

'WebSquare.util.getChildren' 메소드를 사용하여 컴포넌트의 자식 또는 자손 컴포넌트를 배열로 반환받는 예제입니다.

이 예제에서 사용된 '자식'과 '자손' 단어의 의미는 다음과 같습니다.

  • 자식: 대상 컴포넌트의 직계 자식 컴포넌트를 의미하며, 첫 번째 깊이의 컴포넌트만 포함합니다.

  • 자손: 대상 컴포넌트의 자식, 손자, 증손자 등 모든 하위 컴포넌트를 의미하며, 깊이에 상관없이 모든 하위 컴포넌트를 포함합니다.

P00024

2구현된 기능

  • Group의 자식 컴포넌트 반환 받기

  • Group의 전체 자손 컴포넌트 반환 받기

  • Group의 전체 자손 컴포넌트 중 Group, Textbox를 제외하고 반환 받기

3예제 테스트 방법

예제 영역 '로그 확인'의 textarea와 브라우저 개발자 도구의 콘솔에 반환 받은 컴포넌트 정보가 출력됩니다.

1

'자식 컴포넌트 반환 받기' 버튼을 클릭합니다.

예제 영역 '로그 확인'의 'textarea'와 브라우저 개발자 도구의 콘솔을 통해 컴포넌트 정보를 확인합니다. 'textarea'에는 컴포넌트의 ID와 PluginName만 출력되며, 반환되는 객체는 브라우저 콘솔을 통해 확인합니다.

4주의사항

WebSquare.util.getChildren의 인자값은 컴포넌트 객체입니다.

아래는 group 컴포넌트의 id가 "grp_form"인 경우 스크립트 예시입니다.

(O) WebSquare.util.getChildren(grp_form);

(X) WebSquare.util.getChildren("grp_form");

(O) WebSquare.util.getChildren($p.getComponentById("grp_form"));

5구현 예시

5.1자식 컴포넌트 반환받기

' WebSquare.util.getChildren' 메소드를 사용하여 스크립트를 작성합니다.
세부 스크립트는 아래의 예시에 작성되어 있습니다.

Example 5.Script

// 'id' 속성이 'grp_form'인 컴포넌트의 자식 컴포넌트가 담긴 배열이 반환됩니다.
// 직계 자식 컴포넌트(첫 번째 깊이의 컴포넌트)
var arrComponents = WebSquare.util.getChildren(grp_form);

5.2전체 자손 컴포넌트 반환받기

' WebSquare.util.getChildren' 메소드를 사용하여 스크립트를 작성합니다.
- 두 번째 인자 JSON의 'recursive' 속성을 'true'로 설정합니다.
세부 스크립트는 아래의 예시에 작성되어 있습니다.

Example 6.Script

// 'id' 속성이 'grp_form'인 컴포넌트의 자손 컴포넌트가 담긴 배열이 반환됩니다.
// 자식, 손자, 증손자 등 모든 하위 컴포넌트(깊이 상관없이 모든 하위 컴포넌트)
var arrComponents = WebSquare.util.getChildren(
    grp_form, 
    {
        recursive : true
    }
);

5.3Group, Textbox를 제외한 자손 컴포넌트 반환받기

' WebSquare.util.getChildren' 메소드를 사용하여 스크립트를 작성합니다.
- 두 번째 인자 JSON의 'recursive' 속성을 'true'로 설정합니다.
- 두 번째 인자 JSON의 ''excludePlugin' 속성에 제외할 PluginName을 설정합니다.
세부 스크립트는 아래의 예시에 작성되어 있습니다.

Example 7.Script

// 'id' 속성이 'grp_form'인 컴포넌트의 'group'과 'textbox' 컴포넌를 제외한 자손 컴포넌트가 담긴 배열이 반환됩니다.
// 자식, 손자, 증손자 등 모든 하위 컴포넌트(깊이 상관없이 모든 하위 컴포넌트)
var arrComponents = WebSquare.util.getChildren(
    grp_form, 
    {
        recursive : true, 
        excludePlugin : "group textbox"
    }
);

6주요 API

WebSquare.util.getChildren( component , options )
