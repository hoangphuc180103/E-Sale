[AutoComplete] AutoComplete 데이터 입력 여부 검증

1개요

AutoComplete의 'validate' 메소드를 사용하여 값이 선택되었는지 확인하는 예제입니다. validate 메소드는 선택된 값이 있으면 'true'가 반횐되고, 선택된 값이 없으면 'false'를 반환합니다.

interactionMode 속성이 'true'로 설정되면 항상 'true'를 반환합니다.

P00263

2구현된 기능

  • AutoComplete의 validate() 메소드 동작 확인하기

3예제 테스트 방법

1

STEP 1: 초기 상태를 확인합니다.

AutoComplete에 선택된 항목이 없으며 '- Choose -' 문자열이 표시된 상태입니다.

Image 1.브라우저(Chrome) 실행 예시

2

STEP 1: AutoComplete의 값을 선택하지 않고 'Validate 실행'을 클릭합니다.

3

STEP 2: '로그 확인' 영역에서 결과를 확인합니다.

선택된 값이 없으면 'false'가 출력됩니다.

Example 1.Log

[14:35:48] [validate] :false

4

STEP 3: AutoComplete의 값을 선택하고 'Validate 실행'을 클릭합니다.

'A' 항목을 선택합니다.

Image 2.브라우저(Chrome) 실행 예시

5

STEP 4: '로그 확인' 영역에서 결과를 확인합니다.

선택된 값이 있으면 'true'가 출력됩니다.

Example 2.Log

[14:35:52] [validate] :true

4구현 예시

4.1스크립트로 validate 실행하기

'validate' 메소드를 사용하여 스크립트를 작성합니다.

Example 3.Script

//버튼 "Validate 실행"의 onclick 이벤트
scwin.btn_validate_onclick = function(e) {
    // validate 실행 및 결과 저장
    var validate = acb_validate.validate();
    //로그 출력 
    var strLog = "[validate] :" + validate;
    console.log(strLog);
};
