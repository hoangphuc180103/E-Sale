[Generator] Generator를 이용한 Accordion

1개요

Generator는 자식을 구성할 수 있는 컨테이너성 컴포넌트입니다.
Generator 컴포넌트 내의 group을 이용하여 accordion 형태로 동적 구성하였습니다.
다음은 구현된 기능에 사용된 주요 메소드입니다.

  • 아이템 추가하기 : insertChild

  • 그룹으로 accordion 표현 : getChild

4.1[공통] 필수 확인 사항

Generator 사용 시 제약 사항과 유의 사항입니다.

• 아래의 컴포넌트는 반복(자식) 컴포넌트로 사용할 수 없습니다.

Chart, GridView, Menu, Switch, TabControl, TreeView, WindowContainer


• 반복되는 유형이 고정되어 있지 않은 경우, 해당 유형을 미리 정의한 뒤 script로 조건에 따라 노출을 해야합니다.


• 반복된 컴포넌트는 컴포넌트의 ID로 직접 접근이 불가하며, Generator 컴포넌트에서 제공하는 메소드를 사용하여 접근해야 합니다. (컴포넌트의 ID는 중복을 허용하지 않기 때문에 반복된 컴포넌트의 ID는 웹스퀘어 엔진이 동적으로 할당합니다.)


• Generator 컴포넌트는 브라우저에 HTML Tag 'div'로 출력됩니다. tagname 속성 설정을 통해 HTML Tag를 변경할 수 있습니다.

4.3Generator의 자식 컴포넌트를 추가하기

Generator의 'insertChild' 메소드를 사용하여 스크립트를 작성합니다.

세부 설정은 아래의 스크립트 예시에 작성되어 있습니다.

Example 2.Script

//예시1) id가 "gen1" 인 genderator 컴포넌트의 첫 번째에 추가하는 경우
scwin.idx = 0;
gen1.insertChild(scwin.idx);

//예시2) id가 "gen1" 인 genderator 컴포넌트에 순서대로 추가하는 경우
scwin.idx++;
gen1.insertChild(scwin.idx);

4.4Generator의 getChild 메소드 사용하기

Example 3.Script - 추가된 객체의 제목 설정하기

//id가 "gen1" 인 generator 컴포넌트의 현재 인덱스에 해당하는 자식 컴포넌트 중 id가 "txtTitle" 인 컴포넌트의 value를 "Title (해당 인덱스)"로 설정합니다.
gen1.getChild(scwin.idx, "txtTitle").setValue("Title" + scwin.idx);

Example 4.Script - 추가된 객체에 onclick 이벤트 동적으로 추가

gen1.getChild(scwin.idx, "grpTitle").bind("onclick", scwin.toggleAccordion);

4.5Generator의 toggleClass 메소드 사용하기

Generator의 'toggleClass' 메소드를 사용하여 패널의 열림/닫힘 형태를 나타냅니다.
세부 설정은 아래의 스크립트 예시에 작성되어 있습니다.

Example 5.Script

// 아코디언 형태를 표현하기 위해 toggleClass 메소드를 사용한 스크립트 예시입니다.

// 부모 요소에 "on" class가 없으면 추가하고, 이미 있으면 제거합니다.
scwin.toggleAccordion = function () {
    // li 태그에 on class를 toggle
    this.getParent().toggleClass("on");
};;
