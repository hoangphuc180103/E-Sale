[PageList] 총 페이지 수 설정하기

1개요

PageList의 'setCount' 메소드를 사용하여 총 페이지 수를 설정한 예제입니다. 메소드가 호출되면 선택된 페이지는 '1'로 설정됩니다.

P00414

2구현된 기능

  • 총 페이지 수 설정하기

3예제 테스트 방법

3.1총 페이지 수 설정하기

1

STEP 1: 초기 상태를 확인합니다.

'PageList'의 총 페이지 수가 설정되지 않은 상태로 페이지 숫자가 표시되지 않습니다.

Image 1.브라우저(Chrome) 실행 예시

2

STEP 2: 총 페이지 수를 '15'로 설정합니다.

"총 페이지 수를 '15'로 설정하기" 버튼을 클릭합니다.

3

STEP 3: 실행된 결과를 확인합니다.

'1' 페이지가 선택되며 1~10 페이지가 출력됩니다.
화면에 보여질 페이지 수(속성 'pageSize')가 '10'으로 설정된 상태입니다.

Image 2.브라우저(Chrome) 실행 예시

오른쪽에 구성된 버튼(다음 목록 페이지)을 클릭합니다.

Image 3.브라우저(Chrome) 실행 예시

'6' 페이지가 선택되며 다음 목록이 출력됩니다.
화면에 보여질 페이지 수가 '10'이고 총 페이지 수가 '15'이기 때문에 6~15 페이지가 출력됩니다.

Image 4.브라우저(Chrome) 실행 예시

4

STEP 4: 총 페이지 수를 '5'로 설정합니다.

"총 페이지 수를 '5'로 설정하기" 버튼을 클릭합니다.

5

STEP 5: 실행된 결과를 확인합니다.

'1' 페이지가 선택되며 1~5 페이지가 출력됩니다.

Image 5.브라우저(Chrome) 실행 예시

4구현 예시

4.1스크립트로 총 페이지 수 설정하기

'PageList'의 'setCount' 메소드를 사용하여 스크립트를 작성합니다.
세부 설정은 아래의 스크립트 예시에 작성되어 있습니다.

Example 1.Script

//예제 파일에서는 스크립트 scwin.btn_exam1_1_onclick, scwin.btn_exam1_2_onclick에 작성되어 있습니다.

// PageList 'pgc_exam1'의 총 페이지 수를 15로 설정합니다.
pgl_exam1.setCount(15);

5주요 API
